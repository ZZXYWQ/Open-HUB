# Code of Conduct

## Our pledge

We want Open GHub to be a welcoming project for everyone, whatever their
experience, background or identity. Participants are expected to be
respectful, patient and constructive.

## Expected behaviour

- Be kind and assume good intent.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.
- Respect differing opinions and experience levels.

## Unacceptable behaviour

- Harassment, insults, or personal or political attacks
- Sexualized language or imagery, or unwelcome attention
- Discriminatory jokes or language
- Publishing other people's private information without their permission
- Trolling, or deliberately derailing discussions
- Any other conduct that would be inappropriate in a professional setting

## Scope

This code of conduct applies in all project spaces: issues, pull requests,
discussions and any other place where someone represents the project.

## Enforcement

Report unacceptable behaviour privately to the maintainer at
**abid.nnt.g@gmail.com**. All reports are reviewed promptly and kept
confidential.

Maintainers may remove, edit or reject comments, commits, code and issues that
break this code of conduct, and may temporarily or permanently ban anyone whose
behaviour is harmful to the community.
