# COMPX 四个直达板载配置动作

2026-10-27，已有八款 ATK/VXE/VGN 鼠标的九连接增量，不增加完整型号数。

## 原厂事实与配置格式

固定 SHA256 的 ATK HUB 3.2.27 静态源中，原厂菜单逐项把配置 1/2/3/4 传给 `E3.create(161/162/163/164)`，与循环的 255 明确分开。class9、第三字节零及四字节模 256 和 0x55 对应四条独立记录：

|用户目标|方案索引|原生记录|
|---|---:|---|
|配置 1|0|9,161,0,171|
|配置 2|1|9,162,0,170|
|配置 3|2|9,163,0,169|
|配置 4|3|9,164,0,168|

核心动作类型新增 `ProfileSelect(u8)`，使用独立 JSON 对象表达；ATK 的生产预检和驱动只接受索引 0–3。既有动作的 JSON 保持原样，不把直达动作伪装成循环、宏或 DPI 动作。赛睿的穷尽匹配明确拒绝新类型；其他未核对模型仍不得接收这一新动作。

此编号只用于原厂按键目标映射，与当前组 GET 的原始标记编号无关，不能由此推断该标记的值域。

## 接通流程

已核对型号的可编辑非左键能设置为“切到指定板载配置”，方向选择器显示四个配置名称。生产读取、重开、实时设置、离线编辑、保存和 Open HUB 配置导入保留索引。仅写当前按键四字节记录，不立即向鼠标发送切组命令，不占用宏槽或依赖主机宏。

源记录的 161–164 现有独立解释，循环 255 仍单独识别；160/165、非零保留字段或坏校验继续作为未知数据保留。继承 [当前组固定](COMPX-PROFILE-CYCLE.md)：发现实体切组后拒绝旧连接继续写入，当前仍需断开重连后读取新组。

重连/恢复预览新增直达目标的可读名称，并修复循环配置曾被当成“禁用”显示的问题。该显示修改不会把新动作开放给别的型号。

## 验证

新增七项主程序默认测试覆盖：九连接全部可编辑键的四目标组合、其他 EEPROM 与另一鼠标保留、重开读取、四份完整黄金报文、重复设置零 SET、不发送主机切组命令、无宏分配、非法索引/型号/物理键门槛、循环与直达分开、配置原生编译及全部其他多品牌模板拒绝新动作。既有当前组变化测试增加新动作分支。

核心库新增一项测试核对独立序列化、用户标签和非法负数/浮点/越界字节/错误对象拒绝，旧动作 JSON 兼容测试继续通过。依赖库合计 **357 项单元测试、1 项文档测试通过**，包括雷蛇、海盗船、赛睿、核心和输入层。

真实构建 UI 使用原生 DTO，九连接分别保存四个不同目标；Pulsar 两连接和 HyperX 不显示新增选项。九份实际 GUI 保存方案经过生产配置合并/导入、编译和内存驱动回放。另有 **13 项手动恢复、20 项重连 UI 回归通过**，均为模拟后端；这些现有恢复测试不应被当作直达目标实机或恢复功能新增支持的证据。

主程序默认测试 **848 通过、0 失败、67 忽略**，所需 GUI 方案交叉测试显式执行 **1 通过**。TypeScript/Vite 和非测试原生构建通过。前端 JS 为 **814506 字节**，较上一批增加 **781 字节**；没有新增运行时依赖、图片或原厂软件。
