# 赛睿精确型号：开发增量

本增量未发布、未安装，不计入 100 款完整兼容验收。原有 Rival 310 加入更严格的原生参数核对、完整已知方案与灯效编辑；本次新增 Sensei 310 和 Rival 300 两款具体有线鼠标。相同外壳的特别配色版、其他 USB 编号和接收器没有据此直接开放。

| 型号 | USB | DPI | 物理按钮 | 灯区与节奏 |
|---|---|---|---|---|
| Rival 300 | 1038:1710 | 两档，50–6500 / 50；实体键切换 | 六键，五字节表 | Logo / 滚轮；关闭、常亮，3/5/7 秒呼吸 |
| Rival 310 | 1038:1720 | 两档，100–12000 / 100；实体键切换 | 六键，五字节表 | Logo / 滚轮；关闭、常亮、呼吸、循环 |
| Sensei 310 | 1038:1722 | 同 Rival 310 | 八键，包含右侧后/前侧键与独立 DPI 键 | 同 Rival 310，独立两灯区 |

逐型号复用生产编解码器，在任何发送之前检查 DPI 步长/XY/档位选择、回报率、实际键表、键盘与最多三个左右修饰键、六种已知媒体键、灯区和真实周期。主左键保留；未知型号、未核实动作及不存在灯区拒绝。原生输出报告短写只发送一次，失败不把新状态记作已应用。

软件宏使用此型号已验证的 F13–F24 原生键盘映射作为触发，不是板载宏。所有播放方式继续使用逐输入接口的现有宏运行时；实际应用需要与目标鼠标一致且唯一的序列号。没有序列号的实例仍可离线编辑和模拟，不会改为全局鼠标映射。

界面按六键或八键显示，Sensei 的默认 Page Down / Page Up 正确显示；原生键码选项与编码器接收的键码范围一致，已存在但没有文字名称的键码保留原值显示。原有型号固定两档 DPI 的当前档位不能从主机选择，界面不再提供无法执行的切档选项。

两个独立灯区的颜色、亮度和原生节奏随完整方案保存。Rival 300 直接显示三个固件周期；另两款保留实际 16 位循环时长，不再套用与维护者一秒默认向量冲突的 330 毫秒/颜色点推断下限。使用生产 DTO 运行隐藏浏览器编辑，保存的实际方案经 Open HUB 配置包导入，再由生产驱动执行。

这些鼠标不能完整回读硬件参数。初始值为原厂参考模板或本次会话，界面明确说明；按键写入会发送整张已显示的已知键表。完整方案包含未编辑的已知按钮、两个灯区和宏，不能称作原厂状态的完整备份。新增型号的私有 GG 文件转换、可读硬件状态、完整原厂自定义渐变、性能选项、板载宏与明确的硬件持久化交互仍有缺口；实际固件和 OEM UI 品质尚未验证。因此不列为完整兼容。

外观使用原版 Piper 小型 SVG：Sensei 310 专用图和 Rival/300 同外壳家族图，带固定来源和 SHA-256，无脚本、外部图片或新增运行库。二图合计约 50.7 kB 原始文件。
