# COMPX 原厂 class5 组合键原生写入

普通键盘键与修饰键组合现在使用原厂 class5 快捷键表，直接读回为 Key 动作。不再为这些组合键分配 class6 宏槽，也不添加宏编译器的1ms事件间隔。协议无延时字段不等于实机零延迟；原厂触发/执行时序仍待硬件核实。

## 实现

使用既有固定原厂 [qn/V3/地址与文件来源](development/2026-10-28-compx-chord-source.json)，独立编码单键按下/抬起及可选修饰位按下/抬起、事件数量和sum-to0x55校验。普通键盘用途4..0xA4及左右全部八个修饰位，单键8字节、组合键14字节；绑定记录为[5,0,0,80]。没有延时记录或主机输入。仅支持现有精确COMPX型号和已登记非左键；Pulsar独立协议没有接入此写入器。单独修饰键用途仍保留原有class6宏路径，避免回退已实现功能。

32字节表按实体按键固定分配。首次写入前检查原绑定及完整表：全0/全FF空表或可完整解析的既有组合键允许使用，未知内容保留并拒绝。只写新有效前缀，之后所有不透明尾部保留；旧宏槽及其他快捷键表不擦除。

原宏事务的完整快照/条件恢复核心增加精确32字节几何；宏仍为原有384字节几何及原有引用/空槽核对。快捷键事务捕获全部当前组绑定与完整目标表，逐行写入前后核对预期快照，数据读回后才写class5绑定。恢复只接受已尝试行的旧/新完整状态，未触碰区域必须不变。出现外部改动、部分未知行、切组/身份变化或恢复失败时停止，不盲目覆盖、不重试、不声称恢复成功。

没有原子锁、跨进程互斥或正在执行的快捷键/宏读取时机证明。即使模拟故障恢复通过，也不能声称并发写入或运行中执行完全安全；完整验收数量不变。
