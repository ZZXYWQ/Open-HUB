# Open HUB 0.3.4 · 五品牌实验更新

基于 Abidur Rahman 的 [Open GHub](https://github.com/abidr/open-ghub) 修改，保留 GPL 与第三方许可。**仅是实验性版本**，新增鼠标均未实机验证，不代表整品牌兼容。

[下载 Windows x64 EXE](https://github.com/ZZXYWQ/Open-HUB/releases/download/v0.3.4-experimental.1/Open-HUB-0.3.4-x64-setup.exe) · [对应源码 ZIP](https://github.com/ZZXYWQ/Open-HUB/releases/download/v0.3.4-experimental.1/Open-HUB-0.3.4-source.zip)

本批新增 5 个品牌各一款有线鼠标，合计 23 个品牌的限定型号：

- 华硕 ASUS ROG Strix Impact（0B05:1847）：固定两档 DPI、回报率、实际四键、单键映射及四种 Logo 灯效；任意宏未启用。
- Roccat Kone Pure（1E7D:2DC2）：DPI、回报率、已知按键、单次键盘板载宏；灯效未启用。
- 芝奇 G.Skill MX-780（28DA:3101）：DPI、500/1000 Hz、按键与单次键盘板载宏；原灯效字段保留。
- Etekcity Scroll Alpha（1EA7:4011）：六档 XY DPI、回报率、按键与最多 50 事件的单次板载宏；间隔由固件控制，灯效未启用。
- Mars Gaming MM4（04D9:FA58）：DPI、回报率、按键/快捷键与关闭、常亮、呼吸；任意宏未启用。

五品牌分别提供板载读取、预览、导入、编辑与保存 UI；不解析这些厂商的私有文件。未知原厂动作和宏锁定保留，写入前重读、检查当前组及宏归属，写后回读并在失败时尝试恢复。原有罗技、迈从及其他品牌路径保留。

296 项原生测试与 20 组浏览器回归通过；10 份新增界面保存方案重新交给实际驱动模拟执行。正式 EXE 的 28 个精确模拟连接通过；50 个安装载荷文件逐项核对，5 种真实 NSIS 迁移夹具通过。没有新增鼠标实机、全新 Windows 或缺失 WebView2 的安装验收。

安装包 38,792,147 字节，约 37.00 MiB；比 0.3.3 增加 67,409 字节，约 66 KiB。没有新增运行库或打包官方控制中心。新增外观使用两张开源型号 SVG 和三张明确标注的轻量结构示意图。

应用内仍由用户分别选择下载和安装，安装前校验版本绑定签名。本机按用户明确要求在发布后升级，个人配置与备份不上传。EXE 没有 Authenticode 代码签名。
