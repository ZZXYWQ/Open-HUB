# Open HUB 0.3.3 · 实验性版本

修改自 Abidur Rahman 的 [Open GHub](https://github.com/abidr/open-ghub)，保留原项目历史与 GPL-3.0-or-later 许可。**这仅是实验版，不能认定整个品牌兼容。**

- 新增 **HyperX Pulsefire Haste / Haste Wireless**，仅 HP USB ID 03F0:048E / 028E：DPI、回报率、已知按键、单次键盘板载宏、常亮/关闭滚轮灯与只读板载导入。原厂宏/灯效不可读回；宏只验传输及绑定，已绑定的原厂宏和未知动作保留。新宏只写未被其他绑定引用的按键槽，槽内未绑定的旧内容可能替换。不开启循环/鼠标宏，不解析 NGENUITY 文件。
- 新增 **Pulsar X2 V2 Mini**，仅 3554:F507 USB / F508 1K 接收器：四档统一 XY DPI、回报率、当前档位指示灯关闭/常亮及读取导入。按键、宏及其他灯效暂不写入，不解析 Fusion 文件。复用现有小型 COMPX 驱动，保留 ATK/VXE/VGN 的 CID/MID 检查；Pulsar 当前组变化后拒绝继续写入。
- 两品牌分别列入导入菜单，显示精确型号外观和实际可用控制项。新增 4 张小型本地图，约 33 KiB；不包含厂商软件或新的大型运行库。
- **276 项原生测试**通过（273 默认 + 3 项明确输入的交叉测试），**19 组浏览器回归**通过；界面生成的六份方案再经原生校验、保存格式重载与真实驱动模拟执行。另以公开 USBPcap 样本独立核对 HyperX 报文。**这些都不是实机验证。**

本轮增加两个品牌、三个鼠标型号、四种精确连接，当前涉及 **18 个品牌的部分型号**。实机仍只有既有迈从 A7 V3 Ultra+ / MagDock。AULA 狼蛛 SC620/SC580、攻击鲨 X11 等仍在协议研究；不列为已接入。

Windows 10/11 x64；常规安装包约 37 MiB，复用系统 WebView2，缺失时联网补装。保留原应用标识和配置位置。0.3.2 用户可在“外观与设置 → GitHub 版本更新”检查，下载和安装分别由用户选择；不会自动安装到当前电脑。EXE 未取得 Windows Authenticode 证书；独立更新签名绑定版本并在安装前验证。

附件含 EXE、.sig、对应源码 ZIP、SHA256SUMS、更新索引及验证摘要；不含私钥、个人配置、设备备份或厂商安装程序。图片和第三方许可、可编辑 SVG 与对应源码资料均保留。
