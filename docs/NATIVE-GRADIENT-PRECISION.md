# 原生渐变的半百分比位置

开发增量；不发布或安装，不增加完整型号验收数。赛睿原生渐变仍最多 14 个控制点，只扩展已知位置精度。

原始 GG 多色呼吸会在相邻颜色之间放置黑色中点。若颜色位于 0% 和 33%，中点是 16.5%；之前整数格式会拒绝这类方案。现在 ColorPosition 在内存中以整数半百分比单位存储，保留 Copy/Eq 和固定上限，不用浮点作为内部状态，不引入新运行库。

配置 JSON 继续使用原有 `position` 数字字段。旧整数位置仍输出同样整数，16.5 等位置输出半整数；只接受有限的 0–100% 且为 0.5% 的倍数。负数、100.5%、16.25%、字符串、布尔和无效数字拒绝，不静默截断。原生编码执行 `floor(半百分比单位 × 255 / 200)`；首点必须为零，顺序和 14 点上限仍核对。原来的整数位置独立完整报文保持一致。

编辑器以 0.5% 步进显示和修改位置，新增色点也落在同一精度网格。GG 整数颜色位置之间产生的半百分比黑色中点现在均可表达，无需把 16.5% 改为 16% 或 17%。这只改善已核对的多色呼吸/渐变转换，响应、主机串流、方向和其他未核实行为仍不开放；GG 界面周期与实物时序等价仍未测量。

测试包含旧整数和新半整数 JSON 往返、非法精度/越界拒绝、原生完整整数向量回归、半百分比量化距离、两个型号的实际 UI 导入与编辑保存，以及生产存储重载和驱动内存回放。原厂默认三色 0/33/66% 的呼吸中点按 16.5/49.5/83% 保留；两色示例 0/33% 的中点为 16.5/66.5%。本项目没有赛睿实物，量化向量是根据已核对的原生字段计算，不能称作实机抓包。
