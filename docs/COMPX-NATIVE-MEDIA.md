# COMPX 原生媒体按键与完整已知方案

开发分支增量，尚未发布或安装，不增加 100 款完整型号计数。

## 原生动作和 UI

现有明确匹配的 ATK/VXE/VGN COMPX 设备中，9 个连接项、8 款不同鼠标补充上一曲、下一曲、停止、播放/暂停、静音、音量加和音量减。媒体点按使用鼠标自己的板载宏记录，不经过全局鼠标拦截。Pulsar 的不同格式及尚无对应原生宏证据的型号保持拒绝。

编码依据 ATK HUB 3.2.27 的公开静态源：Media_Key 类型为 2，按下/释放分别使用 0x82/0x42，五字节记录携带 usage、扩展位与大端延迟。单次媒体动作采用同 usage 的按下/释放对；保留现有槽上传、校验、回读与绑定恢复路径。只接受已核对的七种 usage；未知扩展、孤立按下或释放及不同的时序不会被误认成简单媒体点按。

按键编辑器按具体型号提供七项媒体控制；板载宏编辑器也可添加媒体点按，和键盘、鼠标及延迟步骤混排。软件宏使用同一种原子 Media 步骤，但仍要求经过序列号核对的独立鼠标来源，不会把软件映射作用到其他鼠标。Windows 媒体输出沿用已有原子按下/释放批次。

## 保存与槽分配

修改已有、且当前已扫描按键中只有此键引用的原生宏槽时，优先复用该槽，避免每改一次媒体动作就消耗新空槽；其他按键共同引用的槽不能覆盖。现有非空且未被当前扫描按键引用的原厂宏仍不当作空槽。其他板载配置库是否共享同一宏池仍需进一步核对，这项实现不能宣称覆盖所有库的引用关系。

COMPX 的“保存完整方案”现在复制实际读出的全部可重映射已知按键、原生宏定义及可读灯区。未知、不允许重映射的左键和未读到的数据不编造默认值。方案编译时把指示灯颜色安排在 DPI 档位变更之后，保证写到用户选择的新档位。

这仍不等于完整原厂闪存备份：未解码动作、其他配置库与私有厂商文件格式仍有缺口。2026-10-27 后续增量已为五款有指示灯的精确型号补充 [全部八档 DPI 颜色表](COMPX-DPI-PALETTE.md)，无灯型号与不同 Pulsar 格式未因此开放色表。其他驱动仅有会话缓存的状态不因此变成已验证的硬件回读。

## 验证

原生模拟覆盖七种媒体编码、回读重开、连续 30 次修改不耗尽槽、共享引用保留、未知 usage/左键/未支持型号零写入。浏览器对 9 个连接项逐一编辑 DPI、媒体按键、新建并绑定含媒体步骤的板载宏；保存的真实 DTO 经配置包导入、生产校验和原生模拟驱动执行。验证同时保留原有后退按键、键盘宏和灯光记录。

本增量通过 431 项默认应用测试、15 项显式交叉测试、282 项依赖单元测试及 1 项文档测试、29 套无头界面回归。开发 EXE 的 32 个内存传输自检通过；无本批新增鼠标实机证据。未生成安装包，已安装 0.3.7 保留。
