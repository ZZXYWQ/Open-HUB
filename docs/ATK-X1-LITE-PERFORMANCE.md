# X1 Lite 性能与省电子集

开发分支新增有静态原厂依据的性能控制，仍非完整型号验收，未生成安装包。

## 原厂事实

固定ATK HUB 3.2.27中，X1 Lite为ko控制器、PAW3395、CID2/MID89。Bu读取/写入EEPROM169起10字节：消抖、Motion Sync、熄灯时间、直线修正和波纹修正，字段各占一个值/校验对。Uu在181起6字节中携带休眠开关、休眠时间及传感器模式；时间单位10秒。LOD使用地址10的值/校验对。

静态核对原厂DebounceDelay的yZ列表0/1/2/4/8/15/20ms，X1 Lite没有noZeroKeyDebounce标记；闲置/休眠Pdt列表30/60/120/180/300/1200/1500/1800秒。SilenceHeight仅向PAW3950/DM额外提供0.7mm，PAW3395保留1/2mm。noFarDistance原厂标记保持，不接入远距离模式。[来源及审计](development/2026-10-28-x1lite-performance-source.json)。原始程序只静态阅读，没有执行或捆绑。

## 行为

型号专属能力表开放上述八个字段及对应既有性能UI。读写沿用原生字节对校验，其他字段和传感器模式字节原样保留。非法消抖3ms、未知时间90秒、LOD0.7mm在通信前拒绝，不替换成最近档位。

配置中心保存和Open HUB配置包导入保留字段；X1 Lite完整已知方案UI同时编辑DPI、回报率、快捷键、颜色/呼吸、滚轮宏和性能，生产回放逐字段读回。原生快捷键仍以宏读回，不改变其内容。

## 验证

三项新增默认测试涵盖三份独立完整SET黄金报文、整份EEPROM未选字节保持、同型号另一鼠标保留、重开读回、非法值零通信，以及三个写入阶段分别在设备动作前/后失败的六组原始状态恢复。

全量1010项通过、0失败、85项显式桥接默认忽略。X1 Lite生产视图导出/实际UI完整方案回放、十连接性能UI方案配置包导入与生产驱动执行均单独通过。原生构建通过，既有前端/资源没有改动，无体积或运行依赖增加。

这些是合成传输和模拟IPC，不是物理固件测量。故障恢复测试证明所构造的稳定设备状态；未据此宣称与原厂软件并发修改时的原子/条件恢复，既有性能事务仍需补强该边界。原厂私有文件、跨组宏池、其他高级参数、实机播放/断电保存和原厂级UI验收仍缺，完整验收保持0/100。已安装0.3.7不变。
