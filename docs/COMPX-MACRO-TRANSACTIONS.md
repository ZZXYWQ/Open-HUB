# COMPX 原生宏的完整槽与当前组引用事务

2026-10-27 开发增量，现有 ATK/VXE/VGN 8 款鼠标的9连接。没有新增型号准入或安装包。

## 具体变化

旧上传路径按10字节分块调用单行写入，失败后直接尝试把宏备份和绑定发回，没有核对整个槽的新状态，也未读回恢复结果。本次将原生宏、原生键盘快捷键和原生媒体动作共同使用的宏上传路径接入独立事务。

事务捕获完整384字节所选槽及当前板载组全部按钮记录。重新确认目标原绑定、当前组其他按钮的宏引用以及空槽计数；分配后空槽已被占用则在首个SET前拒绝。每次写入前后比较完整预期状态，宏正文全部核实后才更新触发绑定。小宏只改它自身的有效前缀，未使用尾部和其他宏槽不清零。

事务行写入不调用带隐式恢复的通用单行写函数，恢复由完整事务统一决定。只有本次尝试过的行可以处于原值或本次目标值，未尝试行、槽尾、其他按键都必须仍为原值。出现第三方/未知部分写入时停止恢复并明确报告不确定状态。允许恢复时先撤回本次新绑定，再倒序恢复改动的宏行，每步完整读回并核对身份与当前板载组；恢复失败不递归重试，不再把“尝试发送”描述成恢复已完成。

身份沿用[原厂四字节当前连接核对](COMPX-UNIT-IDENTITY.md)。宏格式、播放模式、70事件上限和精确型号范围不变；源仍为已固定ATK HUB 3.2.27的协议事实，无新增厂商代码或运行依赖。Pulsar的独立格式和路径未改。

## 仍有缺口

只核对当前板载组的引用，没有凭当前组推断跨库宏池的全局所有权。这里的原始槽快照是事务内存状态，不是新增的完整厂商闪存导出或磁盘恢复文件。没有固件级原子事务、排他锁或在途宏停止确认；读取间发生换组又换回、其他组引用或正在运行的固件宏仍需独立证据。完整状态核对增加读取流量，实际硬件上传耗时尚未测量。
