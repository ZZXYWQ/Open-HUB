## 原厂证据与实现

重新下载同 SHA 的 SC620 1.2.2 官方安装包，仅静态提取程序、两份语言文件与配置。程序 SHA256 为 `cd947c856d287042bfa75e2617ee0488f9d29c9be532588a6cedfd8e3faf7514`，保留反汇编与前轮相同。新增审计核对69处原始指令字节、操作数及两个语言文件哈希。没有运行原厂程序。

菜单构造的动作类型、语言 ID 与 `411110` 编码函数一起证明以下转换：

| 来源类型 | 原厂含义 | 原生四字节 |
|---|---|---|
| 15 | DPI + | F0 01 01 00 |
| 16 | DPI - | F0 01 02 00 |
| 17 | DPI Loop | F0 01 03 00 |
| 19 | 回报率 + | F0 02 01 00 |
| 20 | 回报率 - | F0 02 02 00 |
| 21 | 回报率 Loop | F0 02 03 00 |
| 11 | 火力键 | 21 61 00 00 |
| 24 | 禁用 | 00 开头，附原始控制 ID 对应提示 |
| 26 | 快捷方式 | 按13个明确来源 ID 分别转换 |

类型17的 `F0 01 03 00` 与此前类型9的 `21 55 00 00` 分别建模，不因看起来都是 DPI 循环就合并；固件实际行为及边界仍未测试。火力键只确认原厂名称和编码，没有自造次数、间隔或主机连点。

类型24此前未实现；本次明确其原厂标签为“禁用”，不是恢复。原厂先清零四字节，再根据来源控制 ID 保留提示字节：ID1/2/3 为 `00 01/02/04 00 00`，ID4为 `00 10 00 00`，ID5为 `00 08 00 00`，ID7/8为 `00 38 01/FF 00`，ID9为 `00 21 AA 00`，ID6/10/11保留全零。提示先按来源 ID 计算，再处理4/5的 EEPROM记录映射。用固定枚举表达已知提示，不开放任意四字节命令。

类型26的13种动作是屏幕亮度增加／减少、计算器、我的电脑、我的桌面、主页、邮件、F5刷新、切换应用、截屏、复制、粘贴、剪切。五个媒体用途新增到本模块的受限枚举，其余使用原厂准确的 HID 使用码和修饰位。屏幕亮度是原厂快捷键用途，不是鼠标灯光亮度，也未保证任何显示器都会响应。未知快捷方式 ID 不静默禁用或替换。

已知灯效继续由配置镜像的七种模式及 DPI 颜色转换处理，本次没有捏造独立灯光按键、速度或亮度控制。原厂 AIM 类型27、未标明语义的旧类型10/12及其他未支持动作保持拦截。
