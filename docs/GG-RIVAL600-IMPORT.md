# GG Rival 600：八灯区与抬升距离导入

开发增量，未发布或安装，未增加完整兼容型号计数。本项目无 Rival 600 实物。精确匹配 `rival_600` / `1038:1724`；不会借用 Rival 650、其他型号或配色编号。

只读 GG SQLite，在原有事件、程序关联、事务和保存流程中接入此型号的两个 CPI 档、回报率、七个物理记录、逐鼠标软件宏、八个灯区与原厂八级抬升距离。第三侧键可保存原始混合宏，第七键可单独配置。原厂默认第三侧键禁用不代表没有这个实体键。非标准鼠标输出、原厂任意滚轮动作和未核对宏格式仍会拒绝整份候选。

抬升设置根据本地原厂 GG122 惰性设备描述确认：输出命令为 `00 96 00 01 low high`，原厂界面八级 high 为 `120 / 115 / 110 / 105 / 100 / 95 / 90 / 85`，low 为 high−4，默认是第五级。沿用现有核心的原生抬升选项，不增加全局输入驱动或运行库，不捏造毫米数。写入失败只发送一次，缓存不会标记为成功。原厂关闭传感器或任意非标准阈值组合不借用八级选项，转换时完整拦截。

Rival 600 的灯区坐标和效果索引位于各个 `*_lighting` 记录内，和 Rival 310 的独立 `*_element` 结构不同。按原厂固定八区坐标/索引核对，逐区解析关闭、常亮、渐变和可表达的多色呼吸。只转换没有方向或空间行为的效果；此时独立色序不需要空间坐标，写入使用已验证的逐区原生渐变格式。未激活绘图历史与空间布局编辑状态不迁移。响应、空间、主机串流或错误/缺失区域时拒绝全部候选，不补造默认灯效，也不只保存 DPI。

原厂 accel / decel / angle_snapping 通过 SSE 内核驱动工作，并不是此鼠标的 HID 设置。当前只接受来源里的默认零值；非默认行为会解释并拦截，不把它伪装成鼠标硬件设置，不引入影响所有鼠标的系统映射。原厂宏继续按原始事件转换为此鼠标独立的软件宏，不能称作板载宏。

界面保留八个灯区、八级抬升、完整已知按键及原始宏，通过编辑器和快捷保存两条路径验证同一方案。生产配置存储重载和合并后，再执行真实驱动的内存传输；原始宏的键盘、鼠标及 23 ms 延迟保留。初次模板与会话缓存均不能称为硬件完整读取，保存 Flash 仍需当前连接上成功应用完整硬件方案，不能包含软件宏。

原厂源为 GG122 `3.11.9/20171221202616_squash.sql` 中设备 120 的 JSON 字面值（SHA-256 `a0378f34e280c9a3dd45ecb0e6e7bdf03b09bd1e4d0d88c11f37c66fb5a5b4e4`）、renderer 工厂 83485，以及本地只读解析且完整性校验通过的 `rival-600.edevice`。仅记录协议事实和源摘要；没有执行厂商代码、迁移 SQL 或 Lisp，没有分发厂商程序、设备描述正文、解析密钥或解码环境。源事实和边界见 development/gg122-rival600-native-facts.json。

参考研究包括 [OpenMouse 固定版本](https://github.com/OpenMouse-Project/mouse-protocol/blob/ba20ec3c5b4d6eca934f5771a4e88271b547df2a/src/steelseries/rival-600.ts) 和 [Cisien 的静态描述研究](https://github.com/Cisien/arctis-things/tree/a6b3dbda49c4600cc95041086e75c91524e5c5f5)。仅作静态比较，没有复制这些项目的驱动代码。GG121 参考中的某项读取命令与本地 GG122 描述不同，所以没有直接启用该查询。原厂界面速度与实际固件灯效的物理等价仍待测量。
