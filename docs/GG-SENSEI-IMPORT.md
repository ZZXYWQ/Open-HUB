# GG 私有配置：Sensei 310 八键适配

开发增量，未发布或安装，不增加完整型号数量。只读 GG SQLite 配置解析现在区分 Rival 310 (`1038:1720`, `rival_310`) 与 Sensei 310 (`1038:1722`, `sensei_310`) 的确切编号和型号名，不接受交叉标记或用另一个型号的按钮数量补齐。

Sensei 310 按八个物理记录转换 CPI 两档、回报率、已知原生鼠标/键盘/修饰键和 CPI 动作、支持的软件宏原始事件及播放方式和已核对的应用关联。右侧第六/七键的默认 Page Down / Page Up 保留；第八键可以引用原始宏。主左键保留，越界第九键触发、六/八键错配、缺失宏、未知行为和无法完整表达的应用条件被拒绝。

文件仍用 SQLite 只读连接、query_only、trusted_schema=OFF 和一次读取事务处理。只解析已有数据，不执行厂商迁移 SQL。官方 GG122 惰性迁移中的独立 `sensei_310` 行用于交叉验证八键默认值，Rival 310 的既有官方样例与 GUI 继续回归。数据摘要与边界见 development/gg-sensei-static-schema-evidence.json。

界面显示型号绑定 1038:1722，在相应八键编辑器中检查右侧默认键和第八键宏，修改宏名称、保存后快速保存不会丢失修改。实际界面 Profile 经生产配置存储保存/重载、导入合并及驱动编译回放，检查它不能匹配 Rival 310 或其他品牌。测试不访问 USB、不注入按键、不自动应用导入项。

原厂灯效类型和其他未核实字段仍单独说明，不能声称私有 GG 灯效已经全部转换。已实现的手动原生渐变与 Open HUB 配置包是另一条已验证路径；本项目尚无这些赛睿实物，软件宏的实际输入身份仍须核对，完整 OEM 功能/视觉和硬件保存仍继续开发。
