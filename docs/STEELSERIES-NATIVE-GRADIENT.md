# 赛睿原生自定义渐变：开发增量

尚未发布或安装，不增加完整型号验收。当前仅在 Rival 310 (1038:1720) 与 Sensei 310 (1038:1722) 开放；Rival 300、其他品牌及未知型号不会套用这个协议。

原生编辑器支持最多 14 个色点，每个色点独立颜色和百分比位置、1–65535 毫秒循环周期、灯区亮度，以及两个灯区独立配置。颜色预览、增加/删除色点、固定起点和有序位置与实际方案一起保存。色点列表在独立区域滚动，两个灯区保持紧凑。

共用类型保持固定上限和 Copy 语义，色点数组不带无界动态分配，没有新运行库。生产赛睿编码器使用同一套验证和发送：百分比位置向下取整为 0–255，再编码成相邻色点的距离；颜色按亮度缩放。少于 14 点且未到 100% 时补首色闭合，完整 14 点保持原生数量，不再增加点。RGB 和周期不由主机逐帧发送。

色点数量、顺序、起点、百分比、零周期、数组长度、灯区和型号范围均会检查。Rival 300 不提供原生渐变。跨品牌方案在应用前被拒绝；雷蛇低层效果构造器也明确返回未实现错误，既有原生灯效通过驱动包回归。

独立黄金向量来自固定 [rivalcfg Sensei 310 测试](https://github.com/flozz/rivalcfg/blob/779ea52c68cbf8d21234d9e0d81718225f680819/test/devices/old_specs/test_sensei310.py)。只用 Python AST 提取其字节常量，不导入或执行参考源码；将测试记录里的报告类型标记转换为 hidapi 的报告 ID，比较完整 Feature buffer。覆盖三色一秒/四色五秒循环、百分比截断和闭合距离。事实与边界参考 [rgbgradient.py](https://github.com/flozz/rivalcfg/blob/779ea52c68cbf8d21234d9e0d81718225f680819/rivalcfg/handlers/rgbgradient.py)。提取的原生报文见 development/steelseries-independent-gradient-vectors.json。

界面使用原生 DTO，把实际生成的 14 点完整方案经配置存储保存/重载、Open HUB 配置包导出/导入合并，然后交给生产编码器。验证选定灯区、颜色、位置、周期和另一灯区独立关闭。模拟和实物验收分别记录；这些鼠标无法回读完整灯效，本项目尚无对应实物，不能因此称完整 OEM 兼容。GG 私有灯效的类型/响应/方向和其他行为尚未全部转换，硬件保存交互也继续开发。
