# Open HUB abstract Z-motion icon

Current design direction: abstract left/right zigzag motion, sharp gaming geometry and a restrained ivory/cyan mark. The specific mouse drawing, H mark, orbital emblem and multi-blade proposals were rejected and are not part of the application assets. Generated using the built-in image generation tool, with alpha preserved in production resizing/encoding. Header: public/open-hub.png. Desktop/installer/taskbar/tray: src-tauri/icons/icon.ico and configured PNG variants. Full master: docs/branding/open-hub-abstract-z-master.png, source only; it is outside application resource mappings. No image-generation service or runtime library is included in the program.

## Final generation prompt

Use case: logo-brand. Design ONE refined ABSTRACT app icon for Open HUB. The user dislikes literal mice, glossy pictorial designs, bulky metallic objects and ornamental effects. Concept: the left-right zigzag motion of a mouse, abstracted into a bold original Z-like kinetic emblem. No actual mouse illustration. One compact geometric mark built from three broad clean diagonal-cut strokes, subtly offset/interlocked into a dynamic zigzag, using intentional negative-space cuts. It should feel like a precise high-end esports/hardware brand symbol, elegant and expensive but restrained. Favor an extremely clean flat-vector visual, no material texture, no realistic objects, no 3D extrusion. Soft ivory/platinum main graphic with one small muted ice-cyan accent plane, on a completely smooth matte near-black rounded-square tile. Crisp diagonal edges, optical balance, thick enough to read at 24 pixels, plenty of clear negative space, iconic silhouette, strong contrast. Transparent canvas outside the tile. No literal mouse, no cable, no wheel, no circular ring, no busy multi-blade/gear pattern, no neon motion blur, no giant luminous Z track, no lettering or words, no circuit traces, no rainbow, no existing company logo. One single production-ready icon, centered front-on, not a mockup or design board.
