# Sensei Ten：精确型号开发增量

未发布、未安装；本项目无此型号实物，不增加 100 款完整兼容验收数。只开放有线 `1038:1832`。`1830` 是另一个型号，`1834` 配色版没有据此启用或另行计数。

| 项目 | 已接入的具体行为 |
|---|---|
| CPI | 1–5 档，50–18000，步长 50；可选择当前档，双字节小端 `CPI/50`，数量为启用位掩码 |
| 回报率 | 125 / 250 / 500 / 1000 Hz，原生 `54 00` 命令 |
| 实体键 | 八键表；保留主左键，另外七键可编辑。右侧后/前侧键默认 Page Down / Page Up，第八键为 DPI 键 |
| 已知动作 | 标准五键输出、已核对键码与最多三个左右修饰键、六种媒体键、禁用、DPI 循环 |
| 宏 | 逐鼠标软件宏，原生 F13–F24 触发；输入集合与控制接口必须属于同一唯一物理容器且当前连接未更换。无全局映射 |
| 原生灯效 | Logo / 滚轮两区独立关闭、常亮、呼吸、循环与最多 14 点渐变；半百分比色点与 16 位周期 |
| 板载保存 | 完整已应用的硬件方案、同一当前连接、没有软件宏或恢复记录时，手动发送一次 `00 59 00`；不确定发送不重试 |
| 外观 | 原版 Piper `steelseries-senseiten.svg`，27,924 字节，不引入运行库 |
| 原厂配置导入 | GG SQLite 精确 `sensei_ten` / `10381832`，五槽 `batch_resolution`、当前档、八键、原始事件宏、支持的两区灯效及已有应用关联转换 |

修正了旧驱动误用的 100 CPI 步长和减一编码；Sensei Ten 必须使用独立的 50 CPI 编码表规则。其他型号传感器规则不变。独立维护者的整段输出/灯效报文与 GG 自己的惰性配置和界面转换模块相互核对，没有执行厂商 JavaScript、Python 或迁移 SQL。

GG 的稀疏启用掩码按原槽顺序压缩成启用档位列表，当前槽变为列表索引。例如启用 1/3/5、当前 5，保留 400/1200/3200，当前为第三档；未启用槽位的编辑历史明确不导入。掩码为空、当前槽未启用、范围/显示值不一致、混用两档布局、错误型号或未实现灯效时拒绝整个候选，不静默保存部分内容。

新增界面测试使用生产原生 DTO，覆盖新建方案及两种真实解析结果，操作档位增删和当前选择，保存七个可编辑键、双区灯效与宏，并将实际保存内容交给原生配置存储、重载、导入合并及生产驱动回放。另有同型号双鼠标、短写/失败、重新打开与恢复保护的共享驱动测试。浏览器测试隐藏运行，不操作用户屏幕；内存模拟不注入系统输入。

仍未完成原厂任意滚轮重映射、扩展鼠标输出动作、非默认性能项、所有反应/空间灯效、完整原厂功能与交互质量核对。硬件状态为模板或会话缓存，无法完整回读或确认闪存。原厂宏仍由主机执行；不能宣传为已验证的板载宏。GG 周期按其界面转换公式计算，物理灯效时序等价尚未测量。因此是部分协议实现，不是完整兼容承诺。
