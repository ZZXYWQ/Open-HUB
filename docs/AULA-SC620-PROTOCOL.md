# 狼蛛 SC620 协议开发记录

状态：原生协议基础已实现，未注册自动设备驱动，未计入完整兼容型号。没有新的安装包或实机验证。

协议事实来自 [狼蛛官方驱动列表](https://aulastar.com/mouse/) 的 `AULA SC620-V1.2.2.exe`。仅静态解包和反汇编，没有执行厂商程序、DLL、键盘钩子或安装器。归档 SHA-256 为 `8c2537d687360a2922ec2b11e1710ba6b2612c8d8a3d4d60966fcad39cee9263`，内置配置版本是 1.2.1。原程序散列与地址索引见 [SOURCE.json](../src-tauri/tests/fixtures/yjx-sc620/SOURCE.json)。厂商程序、资源、图标和完整代码不随 Open HUB 分发。

## 型号与协议边界

官方配置给出 USB `A8A4:2255`、2.4G `A8A5:2255` 和接口 MI_02。这些编号也用于其他 YJX 产品，不能据此认定设备就是 SC620，配置中的 `device_type=101` 也没有被当作已证实的线协议身份码。

[K-snake 的 OEM 网页](https://x1a11.yjx2012.com/) 和 [MKESPN W12 的实测协议记录](https://github.com/deepinthewoods/mkespn/blob/7a4c43bd479acc99c68f8a8967f53ddd5cdd063e/PROTOCOL.md) 仅用于交叉核对共享帧结构。不同型号的 DPI 范围、配置长度、按键布局和校验值不能直接复用。W12 上不检查校验值的结论没有推广至 SC620。

## 已实现

- 64 字节原始中断帧、65 字节 Windows 输出缓冲。发送校验值为报告字节 5..64 的和模 256，写在报告字节 4；对应官方程序 `43A450..43A484`。
- 有限类型的只读诊断查询：03/00 身份、08/A5 按键页、0E/A5 配置页。没有任意命令入口；0D/00 是写宏内存命令，绝不当作读取。扫描不调用诊断查询。
- 严格响应长度、命令、子命令、地址、页面和载荷长度检查；先清理有限数量旧消息，跳过完整异步事件，查询只发一次。短写、短读、错误页、持续占用、超时均报错。响应校验算法尚未证实，不虚构 CRC 验证。
- 46 字节配置镜像，六档 DPI、当前档位、六档指示颜色的选择性修改和完整输出编译。DPI 按官方无符号边界检查为 50..26000；步进尚未确认，不静默量化。回报率、传感器位、灯效、保留字节均保留原值。每档指示颜色不等于完整 RGB 灯效。
- 六个按键页，每页 44 字节、11 条四字节记录。鼠标五键、双击、滚轮上下、DPI 循环、组合键及八种媒体动作的编码与解码；八个左右修饰键位均保留。按键修改要求原始四字节一致，不接受重复记录。未知动作、宏指针和其余页面不转成默认值。EEPROM 记录序号尚未标作完整物理按键布局。

配置和按键只有纯报文编译器，暂没有真实写入执行器。要接入实机，仍需型号/单只设备身份固定、页面实际回读、写入恢复及物理按键布局证据；不能用模拟通过替代这些条件。

## 验证与未完成项

15 项 Rust 协议测试覆盖完整报文、参数边界、原值保留、未知宏、错误请求和真实只读传输函数的模拟执行。测试向量根据官方汇编字段存储重建，明确标注为合成向量，**不是实机抓包**。测试数据不进入应用资源，未引入运行依赖。

尚未完成：可靠型号辨识、全部物理控制对应、宏内存/播放方式、通用 RGB 效果及亮度速度、回报率/性能字段的型号语义、官方文件导入、设备图片与完整 UI、写入/恢复、实机测试。SC580X 与 SC680 的官方程序采用其他通信栈，本模块没有将其列为兼容。
