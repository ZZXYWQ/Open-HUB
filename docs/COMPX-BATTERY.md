# ATK / VXE / VGN 电量与充电状态

2026-10-27，开发增量；已有八款鼠标的九个精确连接项，不增加型号计数。具体列表沿用 [COMPX 横向滚动范围](COMPX-HORIZONTAL-SCROLL.md)。Pulsar 不继承本批电量查询。

## 原厂事实与原生读取

固定 SHA256 的 ATK HUB 3.2.27 静态源中，`GetBatteryLevel` 为命令 4，`WS` 的前三个字段是百分比字节、充电标志字节和二字节电压。原厂充电枚举为 0 放电、1 充电；当前读取器只接受完整四字节数据、0–100 的百分比和明确的 0/1 状态。电压单位没有证据，不显示或猜测电压。

原生能力按现有精确型号开放。完整状态读取中追加一次只读查询，解析失败、未知字段、超时或短写不会变成 100% 或沿用上次值，也不阻止已经能读取的 DPI/按键数据。查询后重新核对 CID/MID；身份改变会拒绝整份混合状态。底层仍执行完整报告校验和、长度、命令和错误状态检查，不降低其他写入条件。

原厂静态程序含缺失数据时默认 100% 的逻辑，本项目没有采用。此处没有设置 EEPROM、切换板载组、写入固件或注入操作系统输入。

## 设置面板

设备设置与离线方案显示百分比及充电状态。实时面板提供独立“刷新电量”按钮；刷新只更新电量组件，不调用修改方案的回调，也不替换 DPI、按键、宏草稿。离线数据标明模拟，刷新按钮禁用，不访问设备。读取失败显示“未能读取电量”，清除先前百分比；离开或切换设备后，旧回执不能更新新面板。

不增加自动轮询。当前手动按钮沿用 `multi_battery` 服务，该服务读取完整设备状态，因此仍会执行既有只读参数查询；没有将其描述为单一轻量硬件请求。电量不属于可写配置，不加入导出方案。

## 验证
