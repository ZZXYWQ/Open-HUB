# M HUB 原厂方案转换开发记录

已实现已知格式转换、完整方案持久化、逐鼠标手动应用和专用原生差异写入事务。原厂完整文件预览、宏正文补充和完整参数编辑界面仍待接通；现有 M HUB 按钮仍只导入板载名称/引用，不能据此声称完整原厂导入已交付。本增量没有增加完整型号计数或安装包。

## 已核对的来源

[原厂静态事实](development/mhub-full-template-official-facts.json)记录公开渲染器的哈希、AST 位置、字段和独立数据表。整个分析只读取已认证静态内容，不执行 M HUB 的代码。

原厂 JSON 导出以产品名称作为唯一根属性，内部是扁平方案，包含六档 DPI、独立 Y、启用档数、活动档、USB/无线回报率索引、休眠、消抖、传感器、旋转、LOD 和按键编码。导出移除六个库记录标识字段。原厂名称引用 `macroInfo` 只有槽位到名称，没有事件正文；本机板载索引也只有名称、索引和来源。

宏正文来自明确提供的 `macroListM7` JSON 数组，记录中 `info.keyList` 是事件序列。转换器只提取此方案实际引用的宏，要求名称唯一；不在新目标上按同名猜测内容，不补造缺失事件。外层 `delay` 属于录制偏好，V3 写入器使用序列内的 `time` 事件。当前转换保存的是原生播放内容，录制偏好和全局宏库迁移仍需另外接通。

## 已实现的转换

原厂字段转换为按品牌和精确已启用型号标记的 `Plan`。所有字段先整体核对；未知字段、缺少参数、无法转换的动作、同名宏歧义或缺失正文返回错误，不能生成仅剩 DPI 的不完整方案。当前来源范围仍是既有 `3837:4026`，没有用源目录名称推断新的设备编号。

按键保留一般记录与组合/预设的不同字节序，宏槽字符串按十六进制解释。宏支持四个已核对模式、170 个原厂键盘名称/别名、五个鼠标键、上下滚动及独立延时，通过现有生产宏编译器核对按下/释放与原始字节。未转换的 `22/23/24` 等动作仍拒绝。

新方案保留源文件中存在但尚未启用的 Y 表；按照原厂写入语义，独立 Y 关闭时，编译结果保留目标现有 Y 数值。USB 和无线回报率分别转换；旋转按原始有符号字节和四度单位转换。设备保留位、原始尾字段、其他板载名称和固件信息从新鲜目标快照保留；已知保留位冲突不能覆盖。

宏槽规划同时接收三组完整按键表和当前全部宏。内容逐字节一致时可复用；优先分配空槽，容量不足时只允许使用当前组独占引用的旧槽。其他板载组引用与未分配的用户宏受到保护，不按名称覆写。结果返回逻辑引用映射和需要上传的 `macro_writes`。最终完整快照中的其他宏是保留状态，不能据此在正式导入时全部重新上传。

原始 JSON 入口限制文件大小，并递归拒绝重复键、尾随内容和非法编码。重复的休眠值或宏事件状态不会由 JSON 容器悄悄取最后一项。

## 验证与待接通部分

[验证记录](development/2026-10-27-mhub-full-converter-validation.json)区分原厂格式事实、独立构造的样本、纯编译测试和原生协议模拟。样本不是从用户实机导出的文件，不能当作实物证明。

最初的恢复路径最小重放之外，现已增加专用 `mhub_transaction`。它在管理器锁内核对原始归属与选定连接，读取当前完整快照、三组按键和宏内容，编译差异并在首个 SET 前持久化备份。上传只使用 `macro_writes`；其他板载组引用、未分配宏和内容相同的宏不会被重写。宏每个分块、DPI 每个轴及名称每个分块检查当前板载和引用，新增左键目的位置先于移除旧位置；每个阶段检查读回。完全相同的方案不发送 SET，也不产生新备份。

事务不切换板载组；当前组不匹配时拒绝。发送失败或读回不符可能已有部分内容生效，会报告备份位置；不盲目重试，也不自动覆盖外部后续修改。USB 连接代次不是接收器下的无线鼠标唯一身份，尚未取得 RF 单元身份的证据，不能自动认领或自动套用重连前的配置。

完整 `Profile.mchose` 保留源计划与宏正文，导出使用 `open-hub-profiles/2`；纯旧方案继续使用格式 1。格式 1 夹带完整迈从载荷会拒绝，品牌/型号、互斥来源与 DPI/回报率摘要必须完全匹配。两只同型号鼠标的独立副本经过文件保存/重新加载验证。配置卡分别显示 USB/无线回报率、XY 和启用档数；配置中心、顶部选择器、托盘携带选择时的连接标记，重连后的旧请求在 I/O 前拦截。旧品牌调用参数保持原范围。

[事务与界面验证记录](development/2026-10-27-mhub-transaction-validation.json)包括全套默认测试、真实 React 生成的五次激活请求在生产原生路由/存储/编解码上的内存传输回放、宏容量/共用引用/外部改动/发送错误/读回错误/左键迁移，以及既有迈从和逐设备路由界面回归。这些没有使用实机 SET；软件模拟通过不等于原厂功能或固件行为验收。

后续仍需接通原厂完整文件预览、明确宏库正文补充、完整参数编辑器及用户可见的完整读回回执。通用配置编辑器目前只允许完整迈从方案的名称/应用关联修改，不能单独改摘要造成与真实方案不一致；完整方案参数编辑不可据此算作完成。指定原厂宏库的只读提取也尚未实现。没有用增加入口或省略原厂字段代替这些缺口。
