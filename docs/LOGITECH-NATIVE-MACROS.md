# 罗技原生板载宏：读取阶段

开发分支功能，尚未发布或安装，不增加 100 款完整型号计数。入口在具体鼠标的板载槽 → 编辑按键 → 已有宏的“查看原厂板载宏”。这是真实生产读取路径和对应 UI，不执行宏、不修改绑定、不分配闪存。

## 协议核对

旧 libratbag 源码把 JUMP 放进三字节联合记录，不能据此生成跨页宏。本次交叉检查 [cvuchener/hidpp 的 MacroFormat](https://github.com/cvuchener/hidpp/blob/474ac10db5673da8f2f1c8911414d394c0eb6d12/src/libhidpp/hidpp20/MacroFormat.cpp) 和 [G502 X 的实机协议记录](https://github.com/leodbc/g502x-onboard/blob/cb2952849f82ae91664a610ca9e3e8ce7ee59d55/docs/PROTOCOL.md)：JUMP 为五字节，四字节操作数表示存储类型/页和大端偏移；本项目将其保留为大端扇区地址和十六位偏移。

按公开协议事实独立实现读取器，未复制或分发参考项目代码、运行库。参考项目的硬件结果属于对方，不能计为 Open HUB 实机验证。未合并的 [libratbag PR 1895](https://github.com/libratbag/libratbag/pull/1895) 也只用于比较，不能作为已验证的统一写入格式。

## 当前功能

读取当前物理鼠标、指定槽及普通/G-Shift 层的原始宏绑定，检查 unit-id 或活跃连接键、目录、配置 CRC 和绑定预期值，再沿真实宏页读取。记录键盘与左右修饰键、鼠标位图、媒体按下/释放、延迟、等待/重复控制、跳转及结束标记。不会把按住事件压平为一串点按，不会把设备宏路由成全局软件宏。

以真实扇区尺寸解码，保留完整十六位偏移。仅沿明确跳转换页，不假设自动落入下一物理页。宏页可能没有物化 CRC，CRC 状态仅作诊断，不能一概视为坏页。原始页与未知内容保留在读取结果；读到结束标记表示结构遍历结束，不代表已经证明所有运行语义。

滚轮指令的长度在现有独立证据间仍有差异，XY 与其他未实现指令保持部分读取状态，不推测后续边界。循环地址、非法地址、物理页边界、不完整指令、超过 16 页或 1024 条指令都会明确停止。界面重新读取失败时清除旧内容，避免把过期结果当当前宏。

读取只使用身份、描述和 readSector 操作，前后再次检查目录/配置和身份；没有写命令、配置槽切换、模式切换、输入注入。设备内读取无法构成跨扇区原子快照，外部工具并发修改仍是限制。

## 验证和剩余工作

新增八项默认测试覆盖五字节跨页向量、共享页只读一次、超过 255 的偏移、原始无 CRC 页、循环、未知操作、边界与预算、真实原生只读请求和身份失效。界面使用原生 DTO 展示七条跨页记录，并将实际 selection 交给生产读取器回放；查看后没有待保存按键修改，所有原始扇区保持一致。

当前 445 项默认应用测试、17 项显式交叉测试通过；本增量的宏查看、按键编辑、板载 DPI/身份三套界面回归通过，累计可运行界面套件 31 套。开发 EXE 的 32 个内存传输自检通过，未进行新增鼠标实机操作。

新增宏编译、全局引用清单、空闲空间与原厂宏保护、跨扇区写入/断连恢复、配置包持久化和编辑 UI 继续开发。不能把已有宏可查看或第三方的单台实测算成完整兼容。
