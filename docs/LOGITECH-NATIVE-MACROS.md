# 罗技原生板载宏（开发中）

支持已有宏的只读查看，以及把单次宏写进具体鼠标的空闲板载空间。编辑器在具体设备的板载槽卡片中，支持普通/G-Shift 层与物理按键选择。尚未发布或安装，不增加 100 款完整型号计数。

## 功能范围

已有宏查看保留键盘及八位修饰、鼠标位图、媒体按下/释放、延迟、等待/重复控制、五字节跨页跳转和结束标记。查看器不执行或改写宏，未知操作明确显示部分内容；重新读取失败会清除旧结果。

新增宏支持单次播放、键盘按下/松开、八位修饰快捷键点按、五种鼠标按下/松开、七种媒体点按和延迟。按下/松开必须成对，超长或无效内容拒绝保存，不截断。编辑后要重新检查，再保存。循环、独立修饰键长按、文本和未核对的滚轮/XY 写入继续开发；不会把原生宏偷偷改成全局软件输入。

写入目前要求直接 USB、可靠 HID++ unit-id、内存格式 1、配置格式 1–5、宏格式 1、255/256 字节扇区和最多 32 个用户扇区。其他连接或布局不因此获得写入能力，不能把整个品牌视为完整支持。

## 跨页布局和空间保护

较长单次宏自动使用多个未引用的空页，采用明确的五字节 JUMP，不假设下一物理页自动接续。快捷键和媒体点按的按下/释放保持同页；普通长按事件保持原有事件顺序。所有指令停在有效载荷内，CRC 不被当作指令。最多 16 页、1024 条指令，跳转和结束标记也计入预算，避免生成本程序自己无法完整核对的宏。

空间核对读取全部报告的用户扇区，逐页再次读取比较。扫描每个已存槽的两层全部 16 条记录，包括禁用槽和暂未报告的物理位置。共享宏、明确跨页目标和配置预留扇区均受保护。未知/部分宏或未知绑定类型阻止分配。只使用未引用、有效载荷全 FF 的页；有有效 CRC 的空页也可识别。非空且未绑定的原厂内容不会当作空闲空间。

每次新建/修改暂用新的空页链，不回收旧的非空未引用页，也尚未把多个宏密集装入同一页；持续编辑可能耗尽空间。这是当前实现的明确限制。

## 备份、保存和恢复

保存前持久化整份用户存储原始记录及可读 ROM 数据，文件同步完成后才开始写。先逐页写入宏链，每页完成后读回并核对全库；全部宏页校验通过，才修改选定的四字节绑定和配置 CRC，最后再次核对全库。其他槽、按键、DPI、灯光及已有宏保持原样。普通层至少保留一个会产生左键的物理记录。

不确定写入后，只有实际内存仍属于原值/本次目标值，且其他页、目录、描述和 unit-id 没有变化，才恢复。先撤销绑定，再逐页恢复宏链并核对全库。第三种值、部分损坏或身份改变不作盲目覆盖。主机模式或其他当前槽不会被强制切换；已保存后的当前槽重载/完整视图刷新失败分别报告。

原始备份含无 CRC 页的数据，但原有通用恢复入口仍跳过未通过 CRC 的页，不能宣称能自动还原所有原厂宏存储形态。宏名目前是编辑草稿信息；原生字节码未添加本项目私有名称字段。便携配置包导入、名称持久化、共享/密集分配、安全回收和重复播放仍有缺口。

## 协议证据与验证

旧 libratbag 的三字节联合记录不能作为跨页 JUMP 的正确长度依据。[cvuchener/hidpp MacroFormat](https://github.com/cvuchener/hidpp/blob/474ac10db5673da8f2f1c8911414d394c0eb6d12/src/libhidpp/hidpp20/MacroFormat.cpp) 与 [G502 X 实机协议记录](https://github.com/leodbc/g502x-onboard/blob/cb2952849f82ae91664a610ca9e3e8ce7ee59d55/docs/PROTOCOL.md) 独立支持五字节布局，四字节操作数保留存储类型/页与十六位偏移。[libratbag PR 1895](https://github.com/libratbag/libratbag/pull/1895) 只用于比较，未当作已经验证的统一格式。

按协议事实独立实现，未复制或分发参考工程代码/运行库。测试向量独立重建，不能标成真实 USB 抓包。参考项目的单台实测属于对方，不能计为 Open HUB 实机证据。滚轮长度在独立实现间仍有差异，保持拒绝和原始内容保留。

本项目生产 Device/FeatureRequest 模拟覆盖原生读写和回读、共享/其他槽引用、十六位偏移、CRC 空页、过期全库、目录/身份变化、左键、重载状态，以及单页 36 个和两页 54 个不确定写入阶段。界面实际保存的短宏和 43 步长宏 request 经过相同生产编译、分配、写入和宏读取器回放；255 和 256 字节扇区分别核对。

当前 465 项默认应用测试、19 项显式交叉测试通过。全部 33 套无头界面回归通过。 开发 EXE 的 32 个内存传输自检通过；前端主 JS 压缩后约 222.20 kB，无新增运行时依赖。未操作新增鼠标实机，未生成安装包，已安装 0.3.7 保留，完整型号验收计数没有增加。

后续开发增量增加 [独立的预览连接校验](NATIVE-PREVIEW-CONNECTIONS.md)：稳定配置归属与当前连接标记分别核对；旧连接请求零 HID 拒绝，宏草稿可显式刷新保留。
