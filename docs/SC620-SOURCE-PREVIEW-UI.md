# SC620 原厂文件预览与独立源方案

配置中心的“导入配置”现在按品牌显示“狼蛛 / AULA”，其 SC620 项明确标为**原厂数据库预览／未开放设备应用／开发中**。本轮接通生产解析、实际构建界面、源方案保存重载和静态编译回放；没有把源方案伪装成可直接应用的通用配置。

## 文件到界面的流程

`preview_sc620_source` 接受用户显式选择的 SQLite 或本程序源方案文件。SQLite 使用既有普通文件／8 MiB 上限及只读连接，在同一事务中枚举实际配置 ID、读取所选设置／按键和全局宏库；最多64组文件侧配置。ID 7/42 等仅用于文件内选择，不等于板载组或设备身份。

界面显示六档 DPI、当前档和各档指示色、回报率、消抖、LOD、休眠、滚动方向、电竞和传感器选项，以及已核对的七种灯效模式名称。指示色不会被称作任意灯区颜色。按键列表显示源控制编号和层，不虚构物理位置；宏引用显示来源 ID 对应的槽位。宏库可展开检查保留的原始事件、值和延时字段，不声称已经在硬件播放。

来源设置未转换、未知按键／层、宏 ID 缺失或整库事件不能转换时列出原因。未知设置和事件保留在来源对象中。若所选配置不引用宏，不因文件存在未支持的未绑定宏就上传／替换原生库。`static_subset_convertible` 仅表示已核对来源子集可进入静态准备，`hardware_apply_available` 始终为 false。

UI 没有应用、激活或通用配置保存动作。用户关闭、换文件、取消或读入失败时，忙碌和世代检查防止旧内容变成新结果；错误／取消会清除旧预览及保存按钮。原厂文件没有自动扫描，也不自动应用。

## 独立源方案格式

`export_sc620_source` 保存格式 `open-hub-sc620-source/1`，内容为所选配置的全部已读取设置字段、按键记录及全局宏库，包括未转换值、布局／描述元数据和稀疏 ID。它不是整个原厂数据库或其应用关联表的备份，也不是 `open-hub-profiles/1` 或 `/2` 通用应用配置包。

只创建新文件，不覆盖原厂文件或已有源方案。重载时复算设置摘要，校验来源结构、数量、宏模式、事件次序、重复 ID 和文本长度，拒绝未知 JSON 字段／篡改摘要，不静默丢弃字段。通过浏览器传递的整数须能由 JavaScript 精确表示，避免 ID 在导出时被舍入。未支持的语义仍可原样归档，但不因此变成可执行动作。

通用配置导入器会拒绝这个独立格式；它不进入可自动切换的 ProfileStore，也不触发其他品牌或鼠标的配置匹配。型号身份、设备执行和恢复接通后，还需另外实现设备配置导入／编辑与应用；本轮不能冒充该功能完成。
