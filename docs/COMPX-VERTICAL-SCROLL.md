# ATK / VXE / VGN 原生上下滚动

2026-10-27，已有八款鼠标的九个精确连接项增量，完整型号计数不变。型号列表和精确身份范围沿用 [横向滚动](COMPX-HORIZONTAL-SCROLL.md)，不扩展到 Pulsar 或其他厂商。

## 原厂事实与实现

固定 SHA256 的 ATK HUB 3.2.27 静态源把 `ButtonKeyClass.Wheel` 定义为 11，`ButtonKeyValue1Wheel.Top/Bottom` 为 1/2；`zS` 对应向上/向下滚动，构造时第三字节为零，第四字节令四字节模 256 和为 0x55。独立重建原生记录为 `[11,1,0,73]` / `[11,2,0,72]`。这与横向滚动 class3、宏中的滚轮事件是三种不同格式，不混用。

精确型号的当前可编辑非左键可直接选择向上／向下滚动，修改一个四字节按键记录，不分配宏槽或依赖主机输入。读取和重新打开能区分横向、上下和其他已有动作；方向 0/3、非零保留字段、校验损坏保持未知，不自动改成支持的动作。

设备驱动、配置预检及菜单同时按型号限制。读取的上下动作进入完整已知方案，编辑器显示“滚轮滚动”与具体方向；保存和导入继续使用已有 `Scroll` 配置类型，不新增格式或运行时依赖。未核对的 Pulsar / HyperX 菜单没有该动作，其原生设置也不能绕过门槛。

## 验证

新增九项默认测试涵盖九连接的全部允许编辑按键、上下方向、整个其他 EEPROM 区间与另一鼠标保留、重开读回、完整黄金报文、无变化不写入、未知原值保护、身份变化、短写及错误回读恢复；另覆盖方案编译和不支持的型号/按键。测试复用已有传输故障注入器，黄金上下记录和完整报文独立明确列出。

真实构建 UI 使用生产驱动生成的 DTO，九连接分别保存九份方案，混合保留横向滚动及上下滚动；九份方案经过生产配置合并/导入、编译和内存驱动回放。Pulsar 两连接及 HyperX 作为三项负例，验证菜单没有上下滚动入口。原有横向 UI 九连接及三项负例回归也通过。

完整默认原生测试 **826 通过、0 失败、65 忽略**；所需 UI 方案交叉测试显式执行 **1 通过**。首轮全量回归的一条旧规则曾把上下滚动限定为 DeathAdder，更新后只为本批有独立证据的 COMPX 型号允许上下滚动；反向 DPI 循环、独立 XY 狙击和其他型号继续保持原来的拒绝检查。失败日志保留，最终全量回归重新执行通过。
