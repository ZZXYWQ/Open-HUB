# 板载导入保留已读取性能字段

修复ATK/VXE/VGN现有导入遗漏：设备面板已能读取和设置性能，但“板载配置导入”构建方案时只取DPI、回报率、按键、宏和灯光，保存后丢失性能子集。

现在仅在鼠标能力声明支持性能且本次板载读取返回非空性能对象时，原样加入Tuning设置。不开默认值；false保留为明确关闭，部分读取只导入实际字段，空数据或没有能力声明时不加入。仍直接读取硬件视图，不把主机软件宏会话计划当作板载状态。预览列出实际导入的性能/省电值和单位。

构建UI测试覆盖10份原生型号视图、仅Motion Sync=false的部分读取、缺数据和无能力三种边界，共13份保存方案；构造冲突的主机会话值，确认没有替代板载值。实际保存方案经生产配置合并、编译、驱动及性能事务回放，部分方案保持未导入字段。读取/导入阶段没有设备写入、自动应用或软件输入。

全量1015项通过、0失败、86项显式桥接默认忽略；本次新桥接单独通过。既有27份重复宏方案及三品牌板载导入界面回归通过，前端及原生构建通过。主JS838497字节，增加841字节，无新增依赖。

所有验证为合成传输/模拟IPC。该修复属于板载读取导入，不是原厂私有文件解析器，没有扩大完整型号数；完整验收仍0/100，未生成发布安装包，已安装0.3.7保持。

另已静态核对原厂文件封装链：[固定事实记录](development/2026-10-28-atk-bin-envelope-source.json)。原厂.bin把递归DataView转换结果做UTF-8 JSON和Base64编码；独立依赖固定SHA256并读取确认，原始临时脚本已删除。此事实尚未构成完整文件到原生方案的字段转换，不在UI声称支持原厂文件。
