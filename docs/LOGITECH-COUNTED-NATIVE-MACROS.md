# 罗技板载宏：固定次数完整展开

现有板载宏编辑器增加固定次数播放。仍使用已核对的格式1键盘／修饰键、鼠标、媒体、延时和结束指令，直接生成有限事件程序，不使用主机输入，也没有声称发现新的固件循环计数器。

## 行为与边界

每次先校验一个完整、按下／释放平衡的源序列，再按指定总次数复制完整指令组，只在整个程序最后放一次结束指令。两次表示总共播放两次，不是先播放一次再重复两次。快捷键和媒体点按仍作为原子组，不在中间插入分页跳转；跨页仍用已核对的五字节JUMP。

次数2..255是现有 `Repeat(u8)` 编辑格式能表达的范围，不是固件循环指令的上限证明。实际可保存次数还取决于源序列长度、1024条读取器核对预算、最多16页及鼠标报告的可用空页。纯编译先检查展开后的预算，分配时再计入每页跳转／结束指令；任何超限整份拒绝，不截短或减少次数。

这个后端校验的是单次完整序列后做有限展开。其他后端的2..252保留计数字节约束不用于此处，也没有被全局修改。0和1不接受为固定次数，单次仍使用原模式；按住／开关循环、文本、物理等待和未核对滚动／移动写入不因此开放。

独立左右修饰键每轮都按原始事件完整按下／释放，重叠原子组合、未配对键等错误不能通过次数模式绕过。输入的源步骤、宏标识与名称仍受既有校验约束。

## 界面与存储

默认仍为单次，选择固定次数才显示次数框；改变次数会使已通过的预览失效，必须重新检查。预览显示真正分配需要的板载页数，界面说明次数越多需要的空间越多。设备归属、当前连接、板载槽／层／物理记录与原有事务完全相同。

固件内保存的是展开后的事件程序，没有私有循环头、宏名或次数标记；只读查看会看到全部事件。便携逻辑宏配置导入、名称持久化、密集分配／安全回收仍待接通，不能据此称整套原厂宏已迁移。
