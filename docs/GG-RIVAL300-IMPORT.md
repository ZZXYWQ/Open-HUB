# Rival 300 的旧版 GG 配置与媒体键

开发增量，精确目标为 `1038:1710 / rival_300`；不生成安装包、不安装，不增加完整型号数量。310 / Sensei 310 的平面渐变结构没有套到此型号。

原厂 GG122 自带 3.4.4 迁移中的 Rival 300 默认记录给出旧版字段：`logo_color` / `wheel_color`、`logo_pulsation` / `wheel_pulsation`、两套 `rival_*_color_sequence`，以及六键四字节选择器。界面工厂 4600 指向基础工厂 11090，CPI 比例为 50；默认编码 16 / 32 对应 800 / 1600。导入同时核对 `raw_cpi`，不将显示值冲突、非零修正或型号/布局错配静默转换。

已接入两档 CPI、125/250/500/1000 Hz、五个非主左键的已知鼠标/键盘/修饰键/CPI 动作及原始软件宏、两个灯区的常亮/关闭和固件呼吸。原厂呼吸码 2 / 3 / 4 分别对应原生 7 / 5 / 3 秒；关闭以黑色加常亮模式取消旧呼吸。非空的主机颜色序列、音频/电量等未核实模式会拦截整份候选，不伪装成板载渐变。

同一增量补充三款已接入赛睿型号的 GG 新版媒体选择器 `97`：从首个键码读取单个已核对消费页用法，其余三字节须零。支持上一曲、下一曲、播放暂停、静音和音量增减，直接进入现有原生媒体编码器。空记录、多键和未核实媒体用法拒绝；不把原始动作压成另一种快捷键。相关语义来自 GG 惰性工厂 86737 / 30652，与现有独立 native 媒体向量交叉验证。

UI 按 Rival 300 自己的 50 DPI 步长、6500 上限、六键布局、Logo / 滚轮、固件三个周期和对应外观打开；媒体动作和原始宏可分别查看。编辑和快速保存保留完整已知参数，不自动应用硬件。原厂默认、呼吸、关闭、媒体四组实际浏览器保存结果经生产 Profile 存储重载与驱动内存传输回放。原始 GG 数据库以只读事务读取；原厂迁移仅解析 JSON 字面量，不执行 SQL。

原厂字段、摘要和解析范围见 development/gg-rival300-static-schema-evidence.json。当前主左键仍保留；非默认性能修正、主机序列、其他原厂功能、实物验证与 UI 对等验收仍有缺口。软件宏不是板载宏，实际应用继续要求此鼠标的独立输入核验。
