# ATK HUB 文件的 DPI 灯效、色表、性能与省电转换

在精确型号的原厂文件导入中增加独立选择范围：“导入性能与省电”和“导入灯效与DPI色表”。默认不勾选，原有DPI-only、已解析按键和板载读取流程保留。选择范围或设备变化会清除旧预览；不支持灯效的具体型号禁用该选择，并明确说明未开放。

## 转换范围

固定静态来源：[字段、枚举与单位证据](development/2026-10-28-compx-file-extras-source.json)。原厂文件灯效枚举0=关闭、8=呼吸、9=常亮，亮度/速度各0/1/2；这些不是直接写设备的模式值。校验开关与模式一致，经过既有DpiIndicator模型/能力检查及编码器转换。需要八个完整RGB对象，包括未启用档位的指示色；先排色表再排模式设置。缺失颜色、越界通道、未知模式或错误枚举都会拒绝已选范围，不补默认值。

性能使用当前驱动同一精确TuningCaps：消抖、Motion Sync、可用型号的直线修正、波纹修正、闲置熄灯秒数、自定义传感器休眠开关/秒数及可用LOD。原厂JSON的时间已经是秒，不重复乘十。保留false/0；不猜测布尔、时间、消抖或LOD值。0.7mm仅在既有X1 Pro Max能力中接受；其他型号受自身能力约束。未开放的直线修正/LOD不造值，传感器型号和其余高级字段不作为写入来源。

性能字段范围为当前9款10连接；灯效文件转换是其中6款6连接（X1 Pro Max、X1 Lite、R1、R1 Pro、F1 Pro、F1 Pro Max）的DPI指示灯及八档色表。A9 Plus NK、MAD R/R+不因共享品牌入口获得灯效准入；接收器/装饰灯没有套用此解析器。

预览显示具体性能值、灯效模式、亮度、速度与八档色块/十六进制颜色，并列出未导入范围。未选择的设置继续留在设备中。导入只读文件与保存配置，后续由用户选择匹配鼠标应用。宏正文、多键快捷序列、未开放性能项、其他灯区和未启用档位的DPI数值仍未完整迁移；不声称完整原厂配置等价。
