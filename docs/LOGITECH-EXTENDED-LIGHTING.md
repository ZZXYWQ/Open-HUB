# 罗技现有扩展灯效编辑

开发分支增量，不构成完整型号兼容声明。只适用于既有写入准入范围内、实际报告并已激活 HID++ 0x8070 效果 0x15 / 0x16 的灯区。

## 行为

新增扩展光谱循环和扩展波浪的亮度（1–100%）及饱和度（0–255）调整。界面显示真实当前值，明确应用后才写入。原有方向、设备节奏和所有其他字节逐字节保留；100% 沿用现有原生强度 0 编码。只修改选定单位/连接的一处灯区，只写 RAM。

设备枚举该效果但当前未激活时不开放切换，后端也独立拒绝。这样不需要为未知保留字段、方向或速度填默认值。0x04 基础波浪不同来源的速度布局存在分歧，未由本次扩展。0x8071 缺少已验证的当前状态读回及完整所有权恢复事务，仍未开放写入。

应用复用生产灯区事务的单位与连接核对、最新能力/原值比较、写后精确读回，以及条件恢复。丢失确认且状态仍属于本次修改时恢复原始全部字节；出现第三方参数/方向、档位或能力变化时不覆盖，报告状态不确定。无板载模式切换，不写其他灯区或其他品牌。

## 协议依据

[Solaar 固定协议定义](https://github.com/pwr-Solaar/Solaar/blob/e7304c4c451cc9bb4f206a914844525e67856a28/lib/logitech_receiver/hidpp20.py) 的 LEDEffects 0x15 / 0x16：十字节参数内饱和度偏移 1、节奏 6–7、强度 8、波浪方向 9。交叉核对 [LogitechGDeviceInfo 固定实现](https://github.com/infinitysky/LogitechGDeviceInfo/blob/e19565d9f14d23c7e7c8eb6b674c3de907243515/src/features/rgb.rs) 的扩展效果布局。仅使用协议事实，无复制源码、捆绑厂商程序或新增运行依赖。既有来源和许可保留不变。

## 验证边界

新增四项默认原生测试覆盖两种效果、亮度边界、饱和度边界、精确完整报文、未知方向/节奏/保留字段保持、重复应用零写入、不支持/未激活/重复描述/过期连接/非法输入拒写、超时恢复和第三方改动不覆盖。两个显式桥接测试导出生产 DTO，并将构建后的 React UI 实际请求回放到生产编译/应用/读回路径。界面验证未激活效果隐藏、设备值初始化、两个滑块、选定灯区和无隐式写入；既有常亮/关闭与七种呼吸波形界面回归通过。
