# 底座与电脑独立灯光输出

开发中的修复，不是新的安装版本，也不代表新增完整鼠标兼容。

灯光同步可选择底座、电脑设备或两者。电脑RGB已经独立运行时，底座的原厂效果、恢复和单独音乐律动应只接管底座；不会清空电脑目标、重启电脑效果或停止电脑同步。单独底座律动使用已有底座控制器，电脑效果引擎继续自己的时钟。需要同一时钟时仍在同步输出中同时选择底座和电脑。

工作线程在创建时记录是否拥有底座，取消和恢复依据线程实际所有权，不能依赖可能尚未更新的界面状态。命令之间的底座接管、效果启动和停止需要共享协调，避免并发切换时互相恢复旧值。

界面分别显示底座律动的运行、电平、错误和停止按钮。后台设备状态刷新保留未应用的底座草稿；电脑同步期间仍发现新接底座，但识别不会自动把它加入正在运行的方案。过期的轮询回复不能覆盖较新的启动或停止结果。

模拟验证覆盖真实线程的取消/等待、命令交接顺序，以及界面的目标保留、独立启动停止、错误重试、延迟发现与过期状态回复。测试没有连接RGB服务器、读取音频或写鼠标USB；实体效果、时序和对应型号灯区仍需分别验证。

各鼠标的原生灯效仍按精确型号、真实灯区和已实现能力显示。DeathAdder V3 Pro没有可控制RGB，不能把状态指示灯或独立底座算为鼠标RGB；其他鼠标的亮度量化、支持效果、可读回字段与未知动作保护仍按其各自驱动处理。独立输出修复不扩大任何型号的灯效能力。
