# COMPX 固定次数板载宏

2026-10-27：已有 ATK / VXE / VGN 八款鼠标、九个连接记录的功能增量，不增加完整型号数。

## 来源和范围

固定 SHA256 的 ATK HUB 3.2.27 静态脚本具有 LoopCount 类型，菜单把 frequency 加上类型偏移，原生写入前减去偏移；按键 class6 的第三字节保存次数。既有单次为 1、再次按下停止为 253、按住循环为 254，任意键停止为 255。

此次接通固定重复 2–252 次。上限来自一字节字段和三个已命名保留值的推断，**不是实机测得的固件上限或原厂 UI 上限**。0、非法范围及任意键停止继续拒绝，不混淆为单次或循环。原厂脚本只作静态文本分析，不执行、不随产品分发。

范围为 ATK A9 Plus NK USB/NearLink、X1 Pro Max USB，VXE R1/R1 Pro/MAD R/MAD R+ USB，以及 VGN F1 Pro/F1 Pro Max USB。A9 的两个接口只算一款鼠标；没有把此选项开放给 Pulsar 或 HyperX。

## 实现和界面

宏配置使用独立的 `{ "Repeat": 具体次数 }` JSON，旧播放方式保持原格式。编码、读取、配置合并、生产编译和板载绑定都保留次数；宏内容不因改变次数而被复制或改写，不要求主机软件触发原生播放。应用预检在写入前拒绝无效次数。

宏编辑器显示固定重复选项和 2–252 数字输入。ATK、VXE、VGN 的板载导入预览显示具体次数，保存到配置中心后保留该类型；没有将它显示成再次按下停止。导入读取与保存不自动应用鼠标。

通用输入播放器同时实现有限计数结束、重复按下与松开语义以及中止后的释放清理。零次数直接拒绝启动，避免无限播放；无限模式不会累加计数器。播放测试使用内存 Recorder，不向操作系统注入输入。通用播放器支持该结构不代表其他型号开放了新的板载模式。

## 验证

主程序默认测试 **853 通过、0 失败、68 忽略**。新测试核对全部合法次数、特殊模式区分、独立黄金宏内容、九连接原生回读、另一鼠标保留和非法注册零 IO。

核心、输入、雷蛇、海盗船及赛睿依赖回归 **362 项单元测试和 1 项文档测试通过**。新增输入测试检查 1/2/3/252 次准确事件数量、自然结束、中止释放和重入防护。初次 252 次用例超过测试的三秒等待；实际完成约 3.97 秒，因此仅将测试等待放宽至十秒，保留严格次数和空闲状态断言，没有修改产品延时来绕过检查。Windows 的 1 ms 等待不是调度耗时上限。

真实构建界面配合原生 DTO 和模拟 IPC，保存 **27 份编辑方案**（九连接各 2/10/252 次），核对 **3 个品牌导入预览和保存**，以及 **3 个不支持型号负例**。27 份界面产物另经生产配置合并、编译和内存设备写入/回读交叉测试通过。所有界面测试均未访问真实鼠标。

TypeScript/Vite 和非测试原生构建通过。前端 JS 为 **815154 字节**，较前批增加 **648 字节**，没有引入运行时依赖或原厂素材。
