2026-10-27，开发增量。为已有精确型号增加按键动作，不增加完整验收数。

## 型号和证据

固定 SHA256 的 ATK HUB 3.2.27 静态源中，`ButtonKeyClass.RollSideToSide` 为 3，左右值为 1/2；`GS.create` 的第三字节为零，第四字节令四字节模 256 和为 0x55。由此独立重建左右记录 `[3,1,0,81]` / `[3,2,0,80]` 和完整 17 字节 GET/SET 向量。只读取静态文本，不执行或分发原厂代码。

## 接通流程

已核对型号可把任意当前允许编辑的非左键设置为向左或向右滚动。直接修改一个四字节原生按键记录，不分配宏槽、不运行软件宏、不依赖全局鼠标拦截。读取及重新打开能识别本批两种记录；未知方向、非零保留字段或校验损坏不被归一化成支持的动作。

实时设置和离线方案使用同一原生模型门槛。按键菜单只向符合条件的型号加入 WheelLeft / WheelRight；配置中心的新方案从硬件 DTO 保留已读的横向动作，保存和 Open HUB 配置导入保留原始类型。其他原有动作、DPI、指示灯和宏继续使用各自路径。

写入沿用生产驱动的身份复查、精确行回读及错误时原行恢复尝试。短写会报不确定错误，不自动重发。恢复尝试不是固件原子事务，也不证明外部程序同时改值时可安全回滚。

## 验证

新增十项默认原生测试：九连接的全部可编辑物理键与左右动作、完整 EEPROM 其他字节和另一只鼠标保留、重开回读、独立完整黄金报文、重复应用零 SET、Pulsar/左键/不存在的键零 I/O、未知原值不覆盖、身份改变、短写、损坏回读原行恢复，以及配置编译与导出测试。一个函数可覆盖多个分支，按测试函数计十项。

构建的真实 React UI 使用生产驱动生成的 DTO，九个支持连接保存九份实际方案；另验证 Pulsar 两连接和 HyperX 不出现本批选项。九份方案经过原生配置合并/导入、生产编译和模拟驱动执行，均保留左右记录且没有软件输入依赖。首轮 UI 脚本误找不存在的取消按钮，修正为关闭对话框后完整重跑通过；失败日志保留，不计成功。

默认原生测试 **817 通过、0 失败、64 忽略**；所需界面方案交叉测试显式执行 **1 通过**。TypeScript/Vite 和非测试原生构建通过。没有新增运行时依赖、图片、原厂软件或安装包。
