# 罗技板载宏文件往返

现有板载宏编辑器增加“导入宏文件”和“导出宏文件”。文件保留逻辑名称、标识、单次／固定次数及完整事件，关闭编辑器后可以重新载入；不读取或写入鼠标。它不是 G HUB 私有配置解析器，也不把已有固件宏自动还原为逻辑定义。

## 格式和目标隔离

格式为 `open-hub-logitech-native-macro/1`，根只含 `format` 与 `definition`。不存设备归属、连接、板载槽、层、物理触发按键或地址；在另一只满足既有格式和身份门槛的鼠标上，须重新选择目的地并做全库检查。文件通过校验不保证在该鼠标实际空间中能保存。

生产文件入口复用通用的显式文件大小／普通文件检查和递归重复键拒绝；没有复用 M HUB 的宏协议转换器。每份至多8 MiB。类型、范围、事件配对、原子修饰冲突和静态指令预算由现有罗技编译器核对；未知格式／字段、设备选择字段、重复JSON键、非法编码和尾随内容拒绝，不静默丢弃后保存。固定次数253..255可在该有限展开后端合法表达，其他后端规则保持不变。

导出只创建新文件，不覆盖原厂文件或已有文件；无效定义不创建目标。读回源文件保持原字节。通用设备配置包导入器拒绝这种独立格式，不进入可自动切换的 ProfileStore。

导入仅修改当前宏草稿，保留导入前选择的鼠标、连接、模式层和触发按键，清除已通过的预览。读入失败保留原草稿，并明确提示重新核对。导出也不调用设备保存。真正写入依然必须单独“检查板载宏”再“保存到此鼠标”。文件对话框和读取结果使用既有世代检查，旧异步结果不能接管新草稿。

编辑器可保留最多512条有效源事件；未在快捷下拉命名的合法导入键显示其原键位，避免空白选择或悄悄替换。补齐既有编译器已允许的计算器和主页消费控制选项。独立修饰按下／松开、固定次数与原始事件顺序都通过文件往返保留；最终仍受目标容量和分页预算限制。
