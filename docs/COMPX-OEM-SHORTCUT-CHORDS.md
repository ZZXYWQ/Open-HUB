# COMPX 原厂快捷键读回与文件组合键转换

原厂 class5 快捷键具有独立事件表，不能只看绑定记录或猜测一个键码。本轮把可完整识别的单键/组合键接入实时读回、原厂文件导入和编辑UI；完整快捷序列与原厂执行时序仍未齐，不计完整适配。

## 实现

驱动仅对当前精确COMPX型号、已登记实体按键和规范 `[5,0,0,80]` 绑定读取其独立32字节表，前后核对已固定身份与板载组。检查2–6个完整事件、有效事件区的sum-to0x55校验和、状态/类型/附加字节。未使用的尾部是原厂不透明数据，不因非零而丢弃，也不重写。Pulsar仍使用其自己的既有解析器。

组合键必须恰有一个有效键盘键的按下/抬起，修饰键先按下、主键抬起后再释放，所有状态平衡，不接受重复按下、无对应释放、另一个键、媒体/鼠标/滚轮事件或未知扩展。保留左右八个修饰位。按原厂定义读取的同一modifier记录可携带多个位，也可分散在多条记录；不将多键程序压缩成单键。

文件解析仅接收原厂qn.toArray的四字段事件和三位二进制类型字符串，从实体defaultKey对应的固定shortcutAction名称寻找正文，忽略可修改显示标签和表内顺序。缺少正文、错误类型或未支持序列时拒绝整份按键转换。现有DPI-only模式继续显式排除按键范围。

规范组合键转为逻辑Key动作。当前应用路径仍使用既有class6原生单次宏编译器，不写class5事件表；它会按现有规则产生最小1ms事件间隔。测试证明修饰键/键值/完整释放语义与单次方式，不证明原厂class5精确时间或固件触发行为等价。原class5表在改用新绑定后原样保留，不擦除或回收。

COMPX编辑器现已展示左右全部八个修饰键，导入的右Win等不会因缺少控件而不可见。保存编辑前后均保留完整修饰位，按键预览显示组合键。
