# SC620 原厂设置／按键／宏联合转换

这是未注册驱动的静态开发模块，不是已完成的设备导入或型号 UI。完整验收仍为 **0/100**，安装／发布版本仍为 **0.3.7**。

## 已接通的转换链

显式 SQLite 文件和文件侧 profile ID，通过同一只读事务读取 `t_configdata`、`t_key_macro_data`、`t_macro_data`、`t_macrorecord`。复用 8 MiB 文件上限、普通表／精确字段类型校验和宏库上限；按键表最多 66 条，重复层／控制 ID、NULL、非整数和过长描述拒绝。来源中的布局值、描述和未转换动作原值保留，不用默认动作替换。

准备时复核22键设置子集，指定已有配置镜像对应的目标页；数据库 ID 7 或 42 不解释成板载页。普通层的源控制 ID 4 对应原生记录 4，ID 5 对应记录 3，其余 1..11 的 ID 减一。这来自原厂写入地址计算，不是已验证的物理按钮标签。

当前按键动作转换支持左／中／右、双击、前进／后退、滚轮上下、DPI 循环、受限 HID 键及修饰位、八种媒体控制，以及已核对的板载宏模式。独立 E0..E7 修饰键使用原始跳表转换为八个修饰位；宏事件 VK 转换函数与基本按键 HID 函数分别处理。修饰键本身再叠加非零组合位的情况暂拒绝，不猜测效果。

宏引用通过来源 ID 查找转换库的实际槽位。合成例中 ID 7/42 对应槽位 0/1，并验证按住播放／重复3次的绑定。当前严格转换整份来源宏库；任何未支持事件（包括未绑定宏）阻断宏库替换，不是选择性合并或自动分配空槽。没有宏绑定时保留原生旧库，不因文件存在宏记录就上传。

基本动作和宏动作共享六页原像的引用检查：替换旧宏绑定为普通键时只排除明确选中的记录，其他页及第六只读页的旧宏引用必须保持槽内容，未知宏绑定阻断库替换。只编译原厂允许的前五个写页；重复／越界修改拒绝。静态输出顺序为库分包、库结束标记、变化的按键页、变化的设置页；这不是已验证的设备原子事务或恢复执行器。重复准备相同配置产生零报告。
