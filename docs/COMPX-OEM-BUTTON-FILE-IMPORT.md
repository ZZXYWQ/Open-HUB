# ATK HUB 原厂文件的已解析按键转换

在既有 DPI / 回报率文件转换基础上增加显式“同时导入已解析按键”选项。默认仍是 DPI 范围；勾选后必须完整转换已登记控制，否则整份按键转换报错，没有空宏、默认键替代或静默略过。更改选项、目标、文件或遇到错误都会清除旧预览。

## 实现与范围

原厂 ko 控制器把 key0/key2/key4 的六条记录导出为 `keyActions[0][0]`，记录携带 `defaultKey` / `changeKey`。转换按固定的实体 defaultKey 三字节映射，支持表内顺序变化；不信任标签、索引、名称或文件路径。拒绝重复实体、缺少记录、多层、多行、无效字节及未知实体。独立左键只接受未改动的原厂左键记录，保持现有写入保护。

目前可转换 18 种已经由现有驱动支持的动作编码：禁用、五种普通鼠标输出、DPI 循环/升/降、水平左/右滚动、垂直上/下滚动、板载组循环与四组直达。当前目录共9款10连接，每只按其能力转换四个或五个非左键。MAD R / MAD R+ 原始六条中未开放的第六记录必须保持原始默认；若已改变，明确拒绝，不能把第六记录当作新增适配实体控制。

文件宏（class6）和快捷键（class5）需要另行验证其完整内容，目前拒绝按键转换，不把槽位当作有效宏，也不生成空宏。用户仍可明确选择仅导入 DPI / 回报率。灯效、性能、省电、非活动 DPI 槽位仍未从文件迁移，预览明确写出范围。设备板载读取原有路径继续独立工作。

生产实时读取和文件导入共享纯逻辑普通动作解码器，以免来源一致的记录在两个入口变成不同动作。没有改变 Pulsar 的协议准入、宏内容解码或型号范围；未新增运行时依赖。导入阶段不读写设备，应用仍由用户后续在配置中心选择具体鼠标。
