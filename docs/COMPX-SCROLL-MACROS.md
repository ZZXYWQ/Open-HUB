# COMPX 板载宏的上下滚轮事件

2026-10-27，现有 ATK/VXE/VGN 八型号九连接开发增量，不增加完整型号数。

## 来源与原生格式

核对跨组宏存储时，在固定ATK HUB 3.2.27的ko.setMacro及zv事件编解码发现明确的滚轮事件。滚轮使用class6，状态不含Down的0x80或Up的0x40位；向上值1、向下值255，随后原厂写入同类的值0中性事件，value2为0，延时是事件偏移3–4的大端16位。审计脚本检查固定SHA256、类、方向选择和成对构造，不执行或捆绑原厂JS。[固定事实](development/2026-10-27-compx-scroll-macro-source.json)。

本次逻辑事件为独立Scroll Up/Down，一次一格，不把滚轮扩充为可按住的鼠标键。编码使用方向事件延时1ms及值0中性事件，用户后续延时写在中性事件；每格占两个原生输入事件，35格达到现有70事件上限。读回只无损接受该明确标准对；其他幅度、首事件时序、扩展字段、缺失中性事件或其他类继续拒绝解码，不归一化为猜测的一格。

这没有证明原厂全部滚动时序与本格式等价。旧键盘、鼠标、媒体事件和宏模式JSON不变；新增独立Scroll JSON，不改变MouseDown/MouseUp的原有值域。

## 连接与界面

COMPX宏编辑器新增滚轮点按及每步上下方向，能从原生读回展示、编辑、保存方案、导入和再次上传；只在已确认的COMPX原生宏菜单开放，Pulsar/其他原生格式不因此获得入口。单次、固定次数、按住、切换四模式沿用原有绑定和事务；实际四种播放行为还需实机。

原生上传经过[完整宏槽/当前组引用事务](COMPX-MACRO-TRANSACTIONS.md)，沿用单位与板载组检查。核心播放器为新原子步骤接入已有scroll输出接口，以保持软件宏文件类型完整；路由仍只响应选定鼠标的物理来源，没有全局映射或新输入拦截。其他品牌原生编译器不能因此自动获得新原生滚轮编码。
