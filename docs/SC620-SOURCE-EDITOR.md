# SC620 离线源方案编辑

原厂文件预览现在可以选择“编辑源方案”，修改后先检查并更新预览，再另存为新文件。本轮接通参数、普通层按键和宏播放方式编辑；仍然不是设备应用，也没有开放 SC620 自动发现或写入。

## 编辑能力

六档 DPI、当前档、六个 DPI 指示色，125/250/500/1000 Hz、0..20 ms 消抖、两档 LOD、原厂离散休眠分钟值、滚动方向、电竞模式、三项传感器选项和七种已核对灯效可以编辑。指示色不冒充任意灯区色；没有增加未经核对的灯光速度／亮度选项。来源缺少传感器位字段时不凭空补入未修改位。

普通层控制按来源 ID 显示，支持现有已核对的鼠标、键盘与左右八修饰位、滚轮、DPI／回报率专用动作、火力键、媒体／快捷方式、已存在的宏 ID，以及按来源控制自动生成的禁用。下拉使用标准按键名称并保留当前组合键；少见使用码放在高级选项。仅复用现有标准 HID 标签，未使用迈从按键编码器；显示选项限定到 SC620 已核对范围，不随其他品牌能力扩展而直接放开。

选择已有宏 ID 不会误把 ID 当作槽位。宏播放可改为一次、2..255次、按住播放或直到任意点击停止；修改模式保留全部原始事件、延时设置、名称和来源 ID。仍未提供宏事件新建／删除／编辑，不把未支持事件变成可播放状态。

## 一致性规则

`edit_sc620_source` 接受完整来源和受限的类型化请求。先复核原始来源，再在独立副本修改，最后重新生成设置转换、逐项诊断和宏槽位说明。失败不会替换界面已接受的来源，原厂文件一直未写入。

设置反向转换写回明确原厂字段，保留未知字段和传感器未选中位。只提交表单中与原值不同的设置；按键和宏的“保持当前”不进入修改列表。禁用提示由控制 ID 计算，拒绝客户端提供任意提示字节；普通动作转回来源字段后再次核对其原生编码。重复修改同一控制／宏、缺失记录或宏 ID、未核对层、越界范围和非法播放方式拒绝。

原始布局／描述作为来源元数据保留；修改后实际动作显示来自新类型，不使用可能过期的原始描述。未知动作、宏事件和设置不会因编辑其他项而丢弃；未转换提示和整份准备门槛继续保留。文件内其他配置必须重新读取，编辑结果只携带所选配置 ID，避免把草稿当作整个数据库。

编辑期间禁止保存旧预览。取消仅丢弃表单草稿；检查失败保留草稿供修正，不能保存未接受结果。检查成功后可另存独立 `open-hub-sc620-source/1` 文件，仍不进入可直接应用的通用 ProfileStore。没有设备句柄、系统输入或全局鼠标映射。
