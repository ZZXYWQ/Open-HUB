# COMPX 原厂指示灯模式、亮度与速度

2026-10-27 开发增量，未发布或安装。范围仍为 X1 Pro Max、VXE R1/R1 Pro、VGN F1 Pro/F1 Pro Max 五款现有精确 USB 型号；不增加完整型号验收数。

## 原厂协议与原生实现

在固定 SHA256 的 ATK HUB 3.2.27 静态源中，`Fu` 定义地址 76 的八字节指示灯参数：模式 1/2 为常亮/呼吸，亮度 16/128/255 对应低/中/高，速度 1/3/5 对应慢/中/快，启用标志为 0/1。各参数通常带相邻校验字节，两字节模 256 和为 0x55。没有从源码证明三档速度对应的毫秒周期，因此 UI 不显示编造的周期或百分比。

原厂 `Fu.create(Off)` 只写关闭标志、亮度和速度，不赋值模式；基类分配零填充缓冲区，因此模式及其校验字节均可能为零。对此仅在有效关闭标志和其余已知参数同时成立时，原样保留 `Unspecified`。启用标志为真时禁止未保存模式；其他未知模式、亮度、速度和损坏校验拒绝。不能把这个特定的原厂关闭例外扩大成接受任意无校验数据。

新增 `DpiIndicator` 设置与可选能力/状态字段，承载开关、模式和三个原厂档位，未启用品牌不增加 JSON 字段。驱动先核对型号与完整原始记录，写八字节参数行，再沿用整行回读与失败时原行恢复尝试。无变化不发 SET；短写返回不确定错误，不自动重发。仍不声称 firmware 原子提交或 RF 单鼠标稳定序列号。

颜色继续保存在独立的八档 `DpiColor` 表中，不把三档亮度误变成 RGB 色值，也不把八档颜色伪装成八个物理灯区。指示灯控制行的更改保留 DPI、其他颜色、按键、宏和全部其余 EEPROM 字节。

## UI、旧文件与配置持久化

读取硬件及导入板载配置时，完整已知记录保存为新设置。UI 显示常亮/呼吸、启用、亮度三档、速度三档和当前 DPI 档颜色；切换 DPI 后当前颜色与八档表对应，关闭后仍可编辑并保存参数。未保存模式显示明确占位，先选择效果再启用。原始参数不完整时不编造默认值，已有待应用参数可以显式移除。

旧版 `Lighting` 关闭/当前档常亮配置仍能执行，继续保留原有亮度与速度，不把旧文件里的名义 100% 变成强制最高亮度。编辑旧文件的原厂档位时，先保留明确选择的当前 RGB，再迁移成新设置。新旧两种设置在同一份原生方案中冲突时拒绝，避免提交顺序暗中覆盖。

服务在新方案写入和宏分配前校验完整原始指示灯状态。DPI 等设置先执行，逐档颜色其次，指示灯参数最后；会话只刷新已经选择的设置。配置中心及 Open HUB 配置包保留完整新设置，私有 ATK/VXE/VGN 厂商文件解析未因此完成。

## 验证与尚缺项目
