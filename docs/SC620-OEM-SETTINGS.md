# SC620 原厂设置表和已核对参数转换

2026-10-27。属于 [SC620 协议适配](AULA-SC620-PROTOCOL.md) 的开发增量，没有注册设备、增加 UI 入口或计入完整型号。

## 原厂证据

同 SHA 的官方安装包静态解包后，核对原程序、语言文件及选定机器码。四个回报率控件的标签为 125/250/500/1000 Hz，控件 ID 72/73/74/75 经事件处理写原厂 `report_rate` 字符串 1/2/3/4，配置写入函数直接放到 46 字节载荷的偏移 2。这是 SC620 的四项编码，没有借用其他品牌的位掩码或倒数编码。

`button_respondtime` 来自原厂按键延迟响应控件，中文标签明确单位毫秒；编辑处理限定 0..20，再写载荷偏移 43。此证据证明原厂参数和编码，未实测实际开关消抖时序。原厂其余设置键已提取为事实记录，但未因能看到名字就开放为已兼容性能功能。

可靠型号身份仍没有补证。共享 A8A4/A8A5:2255 和配置文件中的 host-side `device_type=101` 不足以固定 SC620 或单只无线鼠标，仍未自动注册驱动。

## 原生镜像修改

已核对的配置镜像新增回报率和 0..20 ms 按键消抖的独立读取/选择性修改。未修改时完整保留原始字节，未知原始值返回未识别状态，不替换为默认值。非法速率、超范围时间在创建新镜像之前拒绝，不静默量化；DPI、灯效、颜色、传感器/电源位及保留字节仍保留原值。

没有新增实机写入执行器，输出编译仍只产生数据。

## 原厂设置表子集

原程序 SQL 确认 `t_configdata(config_id,profile,key,value)` 的字段顺序。新增显式文件、指定文件侧 profile ID 的只读解析，复用已有 8 MiB 文件门槛、普通表/精确字段校验、只读连接和一致读取事务。读取最多 64 个唯一字段，限制键和值长度；重复、NULL、错误类型、缺字段、非十进制或越界值拒绝，不让 SQLite 隐式转换成可用默认值。

当前转换 16 个已核对键：灯效、回报率、消抖、活动 DPI 索引，以及六个 DPI 数值和六个 COLORREF 颜色。DPI 使用原厂 50..26000 范围，不强加未经证明的步长；COLORREF 依次保留 RGB 三字节。

全部来源键和值仍保留。dpi_flag、scroll_flag、liftoff_height、sensor_flag、sleep_light、e-sports_flag 等尚未完整转换的字段会进入 `unconverted`，阻断整份源配置准备，**不静默丢弃后称为完整导入**。目前的完整原厂配置仍未接通。

准备时从保留的来源字段重新计算 patch 和未转换集合，拒绝只改 patch 或清空未转换提示的结果。此检查不是文件签名或设备身份凭据。文件内 ID 7/42 等不自动解释成硬件页，应用目标仅由调用方提供的原生镜像决定；未来接设备时仍需要连接和型号门槛。本模块没有选择鼠标、切硬件组、自动扫描原厂目录、落盘恢复或 GUI 操作。

## 验证

新增 **10 项默认测试**。所有四种原生回报率与 21 个消抖值组合都检查仅修改偏移 2/43；未知读取值、非法输入及其余原像保留。独立 Python 创建两个来源 profile 的合成 SQLite，已知子集经生产解析及原生镜像编译，与独立重建的完整 65 字节报告一致；读取后原文件逐字节及目录文件数量均不变。这个样本不是原厂或用户导出。

测试另覆盖两个文件侧配置独立、未转换字段保留并拦截准备、预览重算、错误表/视图、重复键、缺键、值类型、长度、范围和 JSON 往返。SC620 模块 **71 项通过**；主程序 **908 通过、0 失败、68 忽略**，非测试构建通过。

没有新增运行依赖、前端资源或原厂素材。合成数据库只在测试模块包含。本次安装包、程序、两个语言资源和配置文件共五份临时载荷已清理，原厂载荷残留为零，没有执行厂商软件。
