# 型号外观资源

Open HUB 0.3.2 按已识别型号匹配本地图片。设备中心网格/列表、原生设备控制、离线方案编辑和可用的原生灯光界面、已识别 RGB 鼠标列表和单鼠标同步预览共用同一解析器。未知型号保留带说明的示意图，不套用其他型号。只有鼠标使用鼠标图片，同名耳机、键盘或接收器不匹配鼠标图片。

当前 38 个外观系列映射，25 张 WebP 产品图 + 18 张 SVG 型号轮廓，总计 668,716 字节。罗技沿用同壳体系列轮廓；G302/G303、G403/G703、G900/G903 等共享上游对应系列图，不能据此认为所有型号的按钮或功能相同。G305 使用官方产品图。

多配色型号可在设备/方案界面选择黑白展示图；配色仅影响外观并在本地记忆，不写入硬件，也不能从 USB PID 可靠推断用户购买的外壳颜色。迈从原有五色选择保留。

产品图片权利属于各原权利人，用于识别硬件，不表示厂商背书，也不随应用 GPL 许可重新授权。缩放、裁掉透明留白并转为 WebP；各图片的源页面/静态资源和打包哈希见 DEVICE-ARTWORK-SOURCES.json。ATK/VXE/VGN 的共用系列图片来自官方控制中心型号注册表。G961 图片仅提取自官方驱动的静态资源，厂商软件不在安装包内。

Piper 矢量图是单独的未修改 GPL-2.0 资源，详见 PIPER-ARTWORK.md，保留其许可和可编辑 SVG 源文件，不重新授权为应用的 GPL-3.0 代码。没有引入 Piper、GTK 或额外图形运行库。

迈从六张旧 PNG 从 2,517,289 字节压缩为 106,280 字节；本次增加所有外观图后，图片资源总体仍比旧版本小。图片显示并不增加新的协议兼容性。
