# 迈从当前板载组备份预览与恢复

开发分支增量，完整型号验收仍为 0/100，已发布与安装版保持 0.3.7。本次没有物理鼠标写入、原厂程序执行或安装包操作。

## 文件与预览

普通文件恢复现在要求先取得预览。选择文件只读，不自动应用。原生预览重新读取当前鼠标和三组按键，显示真实当前值与恢复后的值；不拿可能过期的界面草稿充当当前设备状态。表格包含本组名称、六档 XY DPI、两种回报率、启用档/当前档、LOD、消抖、休眠、旋转、性能选项和六个按键。宏可展开查看模式、事件、原槽及目标槽。

预览选择包含调用方设备/连接、板载组、文件原始字节 SHA256，以及当前完整状态、全局宏和三组按键的组合摘要。恢复前重新读文件与设备并核对，备份后和每个写入阶段继续核对。文件变化、同一路径重连、换板载组或设备数据变化会要求重新预览，过期选择不会重放。

显式所选普通 JSON 文件最多 8 MiB，避免原 1 MiB 限制拒绝包含大量宏的完整导出。递归拒绝重复键，不忽略未知 JSON 字段；检查既有完整备份格式、型号、宏正文、原始参数与摘要一致性，以及鼠标/接收器固件字面值。未解释参数变化、未解析按键尾部和无效 DPI 索引拒绝。原有 v2 默认省电诊断记录可按既有规则迁移，不因此开放 A7 省电写入；简化 raw-v1 诊断文件不是完整恢复文件。

## 恢复范围和共享宏

文件导出包含当前板载组及已读取的全局宏库，不是三组设置的完整镜像。恢复只应用这一个板载组及其实际引用的宏；文件中的其他宏保留在原文件中，不据此覆盖或删除鼠标的无关宏。预览明确说明此范围、未使用的备份宏数量和宏槽重新分配，不自动切换板载组。

恢复复用完整方案的宏分配和差异事务：先复用逐字节相同内容，再使用不受保护的空槽或本组独占槽，保护其他组引用及现有无关宏，调整本组绑定。未知的其他组动作可能包含未解码的宏引用，因此保留全部槽；只有已存在的相同内容可复用，不猜测空闲槽。这个保护同时适用于普通 M HUB 完整方案。容量不足或没有宏正文时，在写入前拒绝。

备份恢复保留能够精确还原的原始表和 USB/无线各自的 DPI 头索引。后续 [实机 DPI 验证](MCHOSE-PHYSICAL-DPI-ROUNDTRIP.md) 确认鼠标 17／接收器 6 的联动 XY 会镜像 Y：此组合不能恢复联动状态下不同的 Y 表，相关备份在写入前拒绝，不能沿用原先模拟的独立缓存假设。DPI 写入可能改变头部索引，因此恢复模式在 DPI 表之后核对并写回参数；完整原厂方案继续保持既有提交顺序。不能把导入原厂模板时“不应用未启用 Y”的语义套成丢掉备份里的 Y 值。

写入前同步保存完整原状备份，按差异上传宏、参数、按键和本组名称，并最终核对状态及所引用宏。普通左键先建立后替换。相同方案不重复写入或新建备份；失败保留原状文件和可能部分生效的错误，不自动重试或盲目回滚。

## 界面结果与验证

成功显示恢复读回结果、宏上传数量和原始备份路径，清除本组参数草稿及写入宏槽的旧草稿。失败清除旧预览和恢复按钮，必须重新预览；同路径重连会丢弃迟到的预览结果。参数、按键使用现有主题和组件，没有新增依赖或图片。

新增七项默认原生测试覆盖共享槽重分配、其他组/无关宏/原像保留、重复应用无写入、文件和设备变化、严格格式和大小边界、固件/未知字段/缺失宏/按键尾部拒绝、未启用 Y 与不同头部索引、未知引用保护、部分写入失败。模拟还让 DPI 命令主动改变头索引，验证之后能恢复备份值。

实际构建的 React 界面以十次 Rust 测试桥调用完成十五项界面检查，包括二十二行设置、宏事件、独立草稿、成功恢复、文件替换和状态变化零 SET、部分失败保留原像及重连取消迟到预览。测试桥每个场景重建相同的已知内存设备与真实临时 JSON 文件，不是物理 USB 会话；没有启动系统文件对话框或实际 Tauri IPC 宿主。

默认原生测试 746 项通过、0 失败、60 项忽略；新桥已实际运行。原有二十二项连接生命周期和十一组草稿界面回归通过，TypeScript、Vite 与非测试开发构建通过。前端 JS 802407 字节，比上一增量增加 6425 字节。[验证记录](development/2026-10-27-mchose-backup-restore-validation.json)。

运行时普通文件接口不再提供无预览恢复；旧源数据回放帮助函数仅在测试构建中保留。显式硬件自测的内部原状恢复是另一条诊断路径，本轮没有执行。鼠标物理按键/宏播放、断电保存、RF 单只身份、身份 FF 和逐型号验收仍未因此完成；底座灯效仍由单独灯光备份管理。

2026-10-27 后续实机发现并修复原厂空名称的恢复编译：仅严格原生备份可保留空板载名称，普通 M HUB 模板仍要求非空名称；不为了通过校验擅自给设备命名。
