# 罗技板载鼠标输出键与组合

开发分支实验性增量，不增加完整适配型号数。物理按键位置仍由当前鼠标的板载描述符报告；16 个输出键指 HID 鼠标按钮位，不代表鼠标有 16 个实体按键。

## 实现

原有单键动作已能编码 1–16，但界面只列前五个。本次将 16 个输出键完整接入既有按键菜单，并新增显式 MouseChord 动作：2–16 个互异输出键编译为原生 0x80/0x01 的大端 16 位掩码。非法位、重复位、空组合和单元素组合整份拒绝，不接受任意原始报文。原有 Mouse JSON 保持兼容；单键使用原有动作。

组合界面有 16 个复选项，普通层和 G-Shift 的编辑独立保留，少于两个输出时禁止保存。保存后使用原生解码结果显示每个组合成员，不再只显示最低位输出键。未选择记录的原厂宏、DPI、灯效和其他层保持。

普通层必须保留一个掩码恰为 1 的独立左键；包含左键的组合不再算独立左键。宏分配与普通按键修改共用这条检查。回归场景分别证明另一个独立左键允许替换原左键、只有左键组合时拒绝且不写宏页。

没有全局键盘/鼠标钩子、软件输入模拟或新增运行依赖。第 6–16 个输出键的响应取决于目标应用，尚无实体固件或应用接收验证。写入继续沿用直接 USB、设备/连接预览核对、目录归属、原记录比较、CRC、备份、精确读回与失败恢复路径，没有扩大设备准入。

## 来源

[Solaar 固定版本 Button.from_bytes / to_bytes](https://github.com/pwr-Solaar/Solaar/blob/e7304c4c451cc9bb4f206a914844525e67856a28/lib/logitech_receiver/hidpp20.py) 的 SEND/BUTTON 类型，将两字节完整值按大端解析及编码。与 [libratbag 固定版本](https://github.com/libratbag/libratbag/tree/8235b5bb6032dea15901ab58a8218956f4494d08) 的 0x80 鼠标按钮掩码事实交叉核对；仅使用协议事实，没有复制第三方实现或捆绑其程序。

核对中还发现 libratbag 将电量指示等部分特殊动作注明为 memory model >= 3，而当前原生写入准入仍为 model 1，故没有直接将该批动作加入可写菜单。MACRO_STOP / STOP_ALL 名称也不能证明在途虚拟机停止确认，未据此开放旧宏页擦除。

## 验证

六项新增默认原生测试涵盖全部单键、低/高位与全位组合的完整黄金记录、非法输入、CRC/单记录补丁、16 号物理记录和双层保留、独立左键规则、生产写入/读回解码及 18 个不确定写入阶段恢复。既有宏左键回归扩大为独立/组合两种场景。

两个显式桥接测试导出生产 DTO，并把构建 React 界面的三条修改（普通层单键 16、组合 2+8+16、G-Shift 组合 1+9+16）回放到生产事务。界面验证完整 16 项、无效组合禁止保存、层间编辑保持、明确保存前零写入和重新打开的组合成员。既有按键编辑和宏编辑界面回归通过。

全量 981 项通过、0 失败、80 项显式桥接默认忽略；本次两项桥接单独通过。前端和原生开发构建通过，前端主 JS 836835 字节，较上一提交增加 1087 字节。均为合成传输/模拟 IPC，不是罗技实机测试。完整验收仍为 0/100，未生成发布安装包，已安装 0.3.7 不变。
