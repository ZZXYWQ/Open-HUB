# 罗技原生灯区开发范围

状态：开发分支已接入 HID++ 0x8070 的动态灯区发现、关闭/常亮控制、回读校验与对应设置界面。属于实验性增量，没有达到完整型号验收，未生成或安装新的安装包。

## 已实现

设置页只在鼠标实际报告 0x8070 时显示“打开鼠标灯光”。打开后读取灯区位置、该区的效果槽、效果编号和当前的 11 字节状态；按设备返回内容显示。效果槽与效果 ID 分开处理，不能假设“编号 1”一定存在于每个灯区。未知原厂效果和参数保持原样，界面不把它们换成模板值。

当前可设置关闭与常亮 RGB。只有直接 USB、可读回当前状态及支持的协议版本允许写入；接收器暂只读，等待永久物理身份固定。每次只修改当前选定鼠标的一个灯区。输出末字节为 0，只写 RAM，不写闪存、不切板载/软件模式，也不修改 DPI、按键、宏、其他灯区或其他品牌。

应用前重新发现能力并比较预览时的原始灯区状态，拒绝过期修改；应用后逐字节回读。若写入超时或回读失败，只在灯区仍是本次目标值、能力和板载模式/档位归属没有改变时恢复原值并回读。若灯区出现第三方新值、能力/档位改变或恢复不能核实，则报告状态不确定，不盲目覆盖，也不报告成功。

## 来源与验证

协议交叉来源为 [libratbag 固定提交](https://github.com/libratbag/libratbag/tree/8235b5bb6032dea15901ab58a8218956f4494d08) 的 0x8070 查询/设置、灯效记录事实，以及 [LogitechGDeviceInfo 的 MIT 灯效实现](https://github.com/infinitysky/LogitechGDeviceInfo/blob/e19565d9f14d23c7e7c8eb6b674c3de907243515/src/features/rgb.rs)。后者固定提交 `e19565d9f14d23c7e7c8eb6b674c3de907243515`，版权 2026 infinitySKYLi，许可随包保留为 Logitray-MIT.txt。没有捆绑其程序或运行依赖。

8 项默认原生测试以及 1 项显式浏览器配置到生产事务的交叉测试已通过。包括效果 ID 与槽不相等、未知原状态、单灯区保留、短回复、丢失写入确认、拒绝、其他软件修改、档位/能力变化、恢复失败、两个同型号传输独立。测试中的 G502 HERO 是合成协议场景，不是该型号的实机兼容声明；本项目没有罗技实机。

新灯光 UI 与已有普通/G-Shift 按键 UI 端到端测试通过，实际产品示意 SVG 可解码。全部应用默认测试 391 项通过，12 项显式配置/导入/只读元数据测试通过。新 UI 只使用原有组件与型号图片，前端 JS 为 711.72 kB 原始 / 217.75 kB gzip，没有新增运行依赖。

后续传输改进将严格读取接到真实 HID++ 接收/请求路径：观察到的 0x10 报文要求 7 字节、0x11 要求 20 字节；错误长度不会补零为成功数据。板载描述符/扇区和原生灯效使用不补齐的 3/16 字节真实协议载荷，旧接口对合法短报文保留兼容补齐。另有生产消费者测试确保这些读取没有落回旧补齐接口。此保证针对 hidapi 实际交给应用的报文边界，不能证明操作系统未隐藏的更底层 USB 错误。

## 仍未完成

0x8071 的软件灯光所有权事务、原生呼吸/循环/波浪等参数、每个型号的速度单位和亮度能力、板载保存、配置中心持久化与原厂 G HUB 灯效导入、原生电脑光同步，以及逐型号实机和原厂 UI 品质验收。当前没有把部分灯区功能计作完整品牌或完整鼠标支持。
