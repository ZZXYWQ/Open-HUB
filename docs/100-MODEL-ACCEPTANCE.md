# 100 种鼠标完整适配目标

用户于 2026-10-26 要求至少 100 种不同鼠标的完整功能、UI 和灯效，达到目标后才生成新的安装包；这替代此前每五个品牌发布一次的规则。已发布并安装的 0.3.7 保留，开发过程不把中间版本当完成品。

按不同市场型号计数，有线/2.4G/蓝牙、USB PID、固件版本和相同鼠标的颜色不重复计数。型号目录条目、品牌导入入口、图片或仅 DPI 实现都不能计为完整兼容。

每个型号需要明确的原厂功能清单、协议来源、连接和固件范围；核对以下适用项目：DPI/XY/档位/回报率，全部物理自定义控制和模式层，板载/软件宏及播放方式，灯区/原厂效果/速度/亮度/颜色，板载槽/导入/导出，性能/消抖/LOD/睡眠，电量和对应外观 UI。硬件没有的功能标记不适用，不用虚构 RGB 来凑完整度。

所有启用功能需经过实际生产编解码与传输调用、黄金报文或独立证据、失效/拒绝/短读/身份改变/恢复测试、完整配置持久化及 UI 端到端验证。模拟覆盖与本项目实机覆盖分别记录；只有模拟不能证明实际固件与原厂功能一致。原厂 UI 品质需要逐项评估交互与视觉，不能仅凭截图称媲美。

未知功能不启用；其他品牌原有功能和逐设备隔离保留。不引入全局鼠标拦截，不分发各厂商完整控制软件；公共协议编解码和小型本地资源按需复用，持续记录体积。

目标当前未完成。现有 23 个品牌的部分支持不是 23 个完整品牌，也不是 100 种完整鼠标；当前没有任何新增型号通过全部上述验收。实际进度由逐型号证据和缺口清单决定。
