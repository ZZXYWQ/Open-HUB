# ATK HUB 原厂 .bin 的 DPI / 回报率导入

这是部分字段转换，不是完整原厂配置迁移，也不增加完整适配验收数量。

## 实现

ATK / 蜻蜓 VXE / VGN 原有品牌导入弹窗保留板载读取，并增加明确标注“仅 DPI / 回报率”的原厂文件选择。用户先选当前已连接的精确型号，再选择原厂 ATK HUB 3.2.27 导出的 `.bin`。Rust 后端读取所选普通文件（最大 8 MiB），严格解码规范 Base64，使用递归重复字段拒绝的 UTF-8 JSON 解析器。没有新增运行时依赖，也不运行原厂 JavaScript。

转换前要求 `deviceConfig.mouseConfig.cidMid` 的 CID=2、MID 属于目标精确型号目录。文件中的 uniqueId、名称、路径、主机输入来源均不成为设备路由或授权。仅接受 `dpiList[].dpi.usesLogical=true` 的已解码实际 X/Y，验证启用档数、当前档位、范围和步长；原厂 reportRate 枚举 0..6 转成 125..8000 Hz，并按当前连接方式的已适配档位校验。未猜测旧原始 DPI 编码。

转换结果只含 Dpi / ReportRate 两种设置，并具有品牌/型号范围；通过现有生产配置校验、保存和驱动执行路径。预览列出数值并明确提醒：按键、宏、灯效、性能、省电、非活动 DPI 槽位未导入，沿用设备现有设置。文件不自动应用。无效文件、型号不符、取消选择均清除旧预览，不能误保存前一份方案。

范围为当前 COMPX 目录的 9 款鼠标 / 10 个连接方式：A9 Plus NK（USB、旧 NearLink）、X1 Pro Max USB、X1 Lite USB、R1 USB、R1 Pro USB、MAD R USB、MAD R+ USB、F1 Pro USB、F1 Pro Max USB。Pulsar 的独立协议不套用此文件解析器；没有按品牌扩大设备准入。
