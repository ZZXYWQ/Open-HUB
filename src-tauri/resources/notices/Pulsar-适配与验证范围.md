# Pulsar X2 V2 Mini 实验适配

本版只接 X2 V2 Mini 的 `3554:F507` USB 与 `3554:F508` 1K 接收器，共一个型号、两种连接。USB 配置接口 1，17 字节 Report 08；不是整个 Pulsar 品牌，也不是 X2 Medium/X2H/Xlite/CrazyLight 或 4K 接收器。

复用现有 COMPX 报文、校验、读回及逐行恢复，没有新增驱动运行时。50–26000 DPI、50 步进、最多四档、统一 XY；125/250/500/1000 Hz；当前档位指示灯关闭/常亮。呼吸、亮度和其他灯区未开放写入。0.3.5 起，右键、中键、后退和前进可独立写入五种鼠标动作、DPI 循环/升降及禁用，写后回读。左键保留。0.3.6 增加原生板载快捷键（点按、一个普通键及最多四个修饰键）。任意板载宏格式仍未启用；软件宏支持单次/再次按下停止，需 Open HUB 运行。

“Pulsar 板载配置导入”预览并保存 DPI、回报率、已知基础按键、完整校验的板载快捷键与能读回的常亮/关闭指示灯，不解析 Pulsar Fusion 文件。未知动作或其他灯效不伪装默认值。打开时只查询并读取；在线状态与当前配置组被固定，组发生改变后拒绝继续写入，须重新扫描设备。未宣称取得过本型号 CID/MID；不套用 ATK 的型号编号，也不删除已有 ATK/VXE/VGN CID/MID 检查。

依据 [Andrew Rabert 的 MIT 协议工具](https://github.com/andrewrabert/python-pulsar-mouse-tool/tree/587f3a996a32aaea0f40e671756808f2f37e7fe2)。仅参考静态协议事实，不运行其 USB reset、恢复出厂或配置切换代码。原工具存在部分未完成的操作，本实现另行校验校验和、DPI 上限、当前组与读回；没有加入未验证命令。

实物图来自 [Pulsar 官方 X2 V2 Mini 商品页](https://www.pulsar.gg/products/x2v2-mini-gaming-mouse)，仅展示外观。当前只有模拟验证，没有 Pulsar 实机，需继续验证 Windows USB 描述符、固件差异及无线唤醒。

按键格式另与 [OpenMouse 固定提交的共享按键记录](https://github.com/OpenMouse-Project/mouse-protocol/blob/23f5bed75d148cabeed19c74838deb31d3f60d02/src/teevolution/index.ts) 交叉核对。未知原厂快捷键/宏记录锁定保留，不套用 ATK 的板载宏载荷。模拟覆盖两种连接、四个可改物理键的全部已知动作、独立校验向量、回读失败逐行恢复、未知原动作和配置组变化。


## 0.3.6 快捷键与软件宏

快捷键独立参考 [pulsar-mouse-linux 的固定提交](https://github.com/packerlschupfer/pulsar-mouse-linux/blob/a18ed8fb963a296d4c5493f51017df32f30e975c/src/pulsar_mouse/drivers/nordic.py)（MIT；Packerlschupfer）。每个物理键使用 0x100 + 32 × 索引的专属记录，按键表 0x05 存指针；不套用 ATK 的 0x06 板载宏。完整校验按下/反序释放、校验和、尾部、容量和其他按键的引用；未知记录保留，读回失败或短写尝试恢复完整记录和绑定。

软件宏通过该鼠标的 F13–F24 点按触发，只响应核对过的键盘输入接口，要求与目标鼠标序列号匹配且无歧义；无法核对时不开放软件宏，原生按键和板载快捷键仍可用。支持单次或再次按下停止，不支持按住循环。触发键也可能传递到其他程序。应用、停止和重启恢复沿用逐设备日志与归属检查，不覆盖外部已修改的按键。

配置中心连接多只同型号鼠标时必须明确选择目标，自动切换跳过歧义目标；可以在设备页面逐只应用。没有加入全局按键拦截或额外驱动。新增功能仅做生产代码与内存 HID/输入路由模拟，未进行 Pulsar 实机验证。

Pulsar 恢复身份额外包含原板载组（0–3）。重启后即使型号和序列号相同，也不将原组的恢复记录写入另一组；缺少组身份的记录保持待核对。硬件切组后需要重新扫描。
