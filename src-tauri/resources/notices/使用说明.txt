右上角齿轮 → 外观与皮肤：可调整界面颜色、背景与面板透明度、磨砂、圆角，并加载/导出最大 8 KB 的 JSON 皮肤。四个预设及自定义外观会自动保留。新图标采用抽象 Z 字动势；图标黑白蓝粉黄红六色选择尚未加入此版。

Open HUB 0.3.1 新增 ATK：A9 Plus NK USB / 老款 10C9 NearLink、X1 Pro Max USB。配置中心按品牌导入可读取匹配设备；DPI、基础按键、键盘点按和板载宏共用现有界面。ATK 尚未实机验证，完整限制见 ATK-适配与验证范围.md。其他 ATK 型号不据此算作支持。

Open HUB 0.3.0 使用说明

安装
运行 Open-HUB-0.3.0-brand-imports-x64-setup.exe，按中文向导完成安装。安装包内含程序与共享 OpenRGB 组件，不需要 Node、Rust 或开发工具。常规安装包复用系统 WebView2，缺少时联网补装；较大的完整离线运行库可单独构建。
默认安装到当前用户的 AppData\Local\Programs\Open HUB。以后重装或覆盖升级可直接再次运行安装文件。支持 Windows 10/11 x64。

设备图片
首页与鼠标控制页使用 A7 V3 Ultra+ 官方图片，可选择白、黑、蓝、红、粉五种图片配色。配色选择仅改变图片，不修改设备身份。

鼠标控制（迈从 A7 V3 Ultra+）
六档 DPI、独立 X/Y、回报率、LOD、传感器、消抖、休眠、按键/组合键、18 个板载宏槽、三组板载配置、按应用切换与配置备份恢复已接入。
固件升级、接收器配对、官方云服务仍通过已安装的官方 M HUB 维护入口使用；本适配版不刷写固件。

灯光同步
首页顶部“灯光同步”不依赖鼠标连接，也可从鼠标页进入。
1. 选择目标：MagDock 或点击“检测电脑灯光设备”选择 OpenRGB 支持的设备。可以单独选择电脑设备，也可同时选择底座。
2. 选择常亮、彩虹波浪、多色渐变、柔和呼吸、流星追逐、繁星闪烁、音乐律动或屏幕取色。
3. 音乐律动支持对称喷泉、全域脉冲、彩色波浪、彩虹律动、节拍流星、节拍闪烁六种方式。可调主色、色带、亮度、速度和灵敏度。
4. 点击“开始同步”。调整后点击“应用并重新同步”。停止时恢复启动前的原厂模式和颜色。
5. 关闭窗口后软件在托盘中继续运行；从托盘退出会停止同步并恢复原灯效。
6. 可导出/导入 JSON 灯光方案。目标设备每次重新检测选择，防止不同电脑设备编号不一致。

底座原厂灯效
常亮、呼吸、七彩闪耀、循环变色、流水、音乐模式，以及灯光开关、颜色、亮度、速度、流水方向、恢复原厂灯效均已接入。前五种原厂效果不依赖软件逐帧驱动。音乐与自定义效果需要软件运行。

电脑联动范围
使用安装包内的 OpenRGB 1.1，通过仅监听本机的 127.0.0.1:6742 服务控制。仅列出的、具有 Direct 模式的设备可同步，不会控制未勾选的设备。
本机已经实测 ViewSonic XG270QG 显示器灯光。其他型号是否可用取决于 OpenRGB 支持；主板、内存等设备可能需要其官方说明中的驱动和权限，本安装器不自动安装内核驱动。
请避免同时运行其他会向同一设备持续写入颜色的软件。固件维护时可使用 M HUB 入口退出本软件后打开官方工具。

屏幕与声音
屏幕模式采样主显示器；HDR、受保护的视频、独占全屏可能影响取色。不会保存或上传截图。
音乐模式读取 Windows 默认播放设备的峰值电平，不监听麦克风，不保存或上传音频；不是逐频段频谱分析。

备份与卸载
鼠标和底座写入前自动备份到 %LOCALAPPDATA%\Open HUB\backups。电脑 RGB 开始同步前也保存原状态。
软件配置位于 %APPDATA%\dev.local.openghub.mchose。默认卸载保留用户配置；仅手动勾选清理数据才删除对应软件数据目录。设备板载设置不会因卸载被重置。
安装包为本地个人适配版，未作商业代码签名。请保留本安装文件与对应源码备份。
配置导入与品牌隔离
配置中心顶部仅有一个“导入配置”按钮。点开后逐个列出罗技 G HUB、迈从 M HUB、雷蛇 Synapse、海盗船 iCUE、赛睿 GG，以及 Glorious、G-Wolves、DreamMachines、Genesis、Machenike、Mad Dog、T-Dagger、Marvo 的指定型号板载读取入口。各项标明支持型号与内容；没有“多品牌”卡片或折叠品牌组。
选择品牌后直接读取本地配置、选择源文件或读取指定鼠标板载配置，预览后选择条目导入。导入仅写本程序配置库，不立即改写鼠标。Open HUB 自己导出的配置包从同一窗口底部“恢复 Open HUB 备份”进入，不代表官方私有文件都能解析。
G HUB 转换 DPI、回报率与应用关联，暂不转换官方按键、宏、灯效。M HUB 只读解析 %APPDATA%\MCHOSEHUB\files\config\mc_main_store_key.json 的 A7 V3 Ultra+ 三组板载名称与引用，使用设备已经保存的参数；不迁移账号或令牌，不修改官方文件。
雷蛇 Naga V2 HyperSpeed 的已实现 Synapse 格式、海盗船 M65 PRO RGB 的已实现 iCUE 格式、赛睿 Rival 310 的 GG 数据库格式，可以转换支持的 DPI、按键及宏，检查编辑后模拟并保存。未知动作、型号、层或执行方式不会被静默省略后保存为完整方案。
软件宏需要程序运行，并明确选择此鼠标的输入来源。再次连接或恢复记录时核对目标型号、身份和来源。M65 回报率变更可能重连 USB；写入结果不确定时只允许在核对后的界面显式重试，不自动重发。
M65 和 Rival 310 的部分读回是缓存，不代表未实现的实时硬件查询。Viper、DeathAdder 以及其他型号能力各不相同，详见同目录《鼠标品牌接入范围.md》，不能把某个品牌或灯光入口理解为全部功能支持。
配置按实际品牌/型号筛选；导出当前筛选下的 Open HUB 配置包会保留完整支持方案。未连接匹配鼠标时应用按钮禁用，原有罗技和迈从控制器保持独立。

灯光与设备选择
灯光页按实际设备能力显示原生鼠标、底座及 OpenRGB 设备，可筛选品牌、鼠标、电脑 RGB。进入灯光页或主动扫描才启动 RGB 检测，普通 DPI/按键配置不启动 RGB。
设备身份按厂商、型号、序列和接口匹配。新设备不自动加入正在运行的同步；点击开始同步后才写入。电脑灯光可单独同步，也可与已选择鼠标和底座联动。
导入灯光方案后重新匹配设备身份，原设备未连接时不自动替换成其他品牌；单独电脑方案不强制加入底座。只有实际可用的灯光能力才显示对应控制。

其他已适配型号
SinoWealth 通道包含 8 个品牌的 11 条型号/固件记录，支持匹配型号的 DPI、回报率、按键和本程序记录的板载宏。原厂宏内容无法读回。官方软件写入鼠标后的当前板载参数可读取，私有文件不是通用解析格式。
离线编辑选择确切型号与固件，运行不操作 USB 的模拟校验后保存；没有匹配鼠标时不能向其他设备应用。

验证范围与兼容升级
三品牌新增型号以生产驱动加模拟 HID 和输入接收器测试，不是实机通过。只有迈从 A7 V3 Ultra+ 与 MagDock 已有可用实体设备；其他品牌不能据此声称全系列兼容。
本机已验证旧版升级、同版本覆盖安装和清空程序目录后的重装，保留原有配置与备份。未在全新系统、新用户或缺少 WebView2 的环境中验证。更完整的范围见《鼠标品牌接入范围.md》。
Open HUB 保留旧版内部应用数据标识，默认卸载保留配置。旧本地适配版备份复制到独立的 legacy-mchose-N 目录，不覆盖现有备份或前次迁移；复制失败先中止迁移。官方 G HUB、M HUB 不被卸载。
