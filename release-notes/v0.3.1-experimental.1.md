## 改动与适配

- 改名 Open HUB，保留罗技 HID++ 路径，新增按品牌/型号/身份隔离的适配、配置中心与功能界面。
- 迈从 A7 V3 Ultra+ / MagDock：DPI、性能、按键、板载宏、板载组、底座灯效与同步；M HUB 本地板载名称/引用导入。
- 雷蛇 Naga V2 HyperSpeed、海盗船 M65 PRO RGB、赛睿 Rival 310：各自已实现的 DPI/CPI、回报率、按键/软件宏、有限 Synapse/iCUE/GG 转换。
- 其他指定雷蛇型号与 8 个品牌的 11 条 SinoWealth 型号/固件记录按能力提供部分控制。
- ATK A9 Plus NK（373B:1115 / 老 NearLink 10C9）、X1 Pro Max USB（373B:1017）：八档 XY DPI、回报率、基础按键、键盘点按、板载宏、板载读取导入；X1 指示灯关闭/常亮。**没有 ATK 实机。**
- 灯光按真实能力选择目标，OpenRGB 按需运行；新抽象 Z 图标、配色、透明度、最多 8 KiB 的 JSON 皮肤。

完整的 **14 品牌部分型号** 和边界见 [适配表](https://github.com/ZZXYWQ/Open-HUB/blob/main/MOUSE-BRAND-SUPPORT.md)。RGB 兼容不等于 DPI、按键或宏兼容；官方配置转换不保证支持所有软件版本和格式。

## 实机、模拟与未覆盖范围

实机鼠标/底座仅有 **MCHOSE A7 V3 Ultra+ / MagDock**。其他新增型号采用生产驱动 + 内存 HID，界面采用模拟 Tauri，**模拟通过不等于实机通过**；未重新做罗技实机回归。

0.3.1 的 239 项原生测试、15 组浏览器回归通过，生产构建及安装器载荷核对通过。在当前 Windows 用户下完成 0.3.0 → 0.3.1 升级，11 个配置/界面偏好文件在升级后、首次启动前不变，新版窗口已启动并响应。历史依赖回归为共享驱动 289 单元 + 1 文档，Synapse 解析器 148 单元 + 3 集成测试。

未验证全新 Windows / 新用户、缺失 WebView2 的联网补装、其他实机、所有固件变体及桌面透明效果的完整人工视觉检查。

**尚未接入：VXE R1 / MAD R、VGN F1、AULA SC620 / SC580。图标六色切换也尚未实现。**

## 安装和许可

Windows 10 / 11 x64，按当前用户安装；复用系统 WebView2，缺少时联网补装。本 EXE **未签名**，不继承上游 SignPath 声明；本分支自动更新禁用，后续从本仓库手动安装。测试前备份配置，并退出官方控制中心以避免设置冲突。
