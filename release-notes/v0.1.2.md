## What's new

### On-board memory
- **View** the profiles stored inside your mouse: DPI levels, report rate, button bindings and the factory profile (Device settings → On-board memory).
- **Edit** a slot's DPI levels, starting level and report rate. These settings work even with Open GHub closed, in on-board memory mode.
- Every write is **backed up first** and **verified** by reading it back. You can save a backup to a file and restore it at any time.

### Other changes
- The installer now shows a privacy notice. Update checks can be turned off in App settings.
- Releases are built by GitHub Actions, ready for code signing through the SignPath Foundation.
- A new README, contributing guide and issue forms. Device reports are welcome!

**Tip:** quit G HUB while using Open GHub. On-board memory writes are refused while G HUB's agent is running.
